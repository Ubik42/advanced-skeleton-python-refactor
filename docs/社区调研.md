# 社区调研（2026-09-07）

## 结果

本轮公开检索没有找到可直接采用的 AdvancedSkeleton 6.x 核心 Python 重构或等价的开源迁移仓库。

- `dcc-mcp-maya-advancedskeleton` 提供 Python/MCP 集成与受限能力调用，但要求用户已安装并授权 AdvancedSkeleton；它不重新实现核心，也明确不分发 ADV 源码。
- PyMEL 提供 `pymel.tools.mel2py`，能批量做语法级转换；官方文档同时说明全局变量同步、数组、`catch/catchQuiet`、注释与格式等转换限制。因此适合做局部草稿，不适合作为 8 万行单体脚本的一键重构方案。
- mGear 是成熟的开源 Python Maya rigging framework，可参考其包布局、组件化 rig builder 和测试方式，但它是另一套产品与数据模型，不能作为 ADV 的直接转换结果。
