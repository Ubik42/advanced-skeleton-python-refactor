# 剩余开发清单

本清单记录完整工程的未完成范围。阶段通过只表示对应功能已有证据，不表示 AdvancedSkeleton 全量能力已经替代。开发顺序保持 Maya-first、Blender-second；先连贯实现一组工作流，再集中运行相关回归和后台验收，不按单文件或小功能发布版本。

## 已有基础

Fit 数据编辑与往返、标准 30 / 70 关节 Body、四肢和五指控制、固定双段脊柱、当前姿态匹配与空间切换、显式蒙皮、权重文档、Root Motion、导出骨架与 FBX、显式 MoCap 映射和 Body bake 已有实现。角色登记、保存重开、全身静态姿态与实际蒙皮恢复已完成独立进程验证。

上述能力受各模块声明的拓扑、归属、动画和连接边界约束；代理网格通过不等于生产资产兼容性已经完成。
