# 动捕与骨架发布

当前 MoCap 入口按显式的来源关节与 Body 关节映射建立临时约束，再把采样姿态烘焙到 Body。FBX 入口只导出已烘焙的独立导出骨架，导出前检查范围、来源依赖和目标文件占用。

映射预设由来源/目标关节短名、平移与旋转传递开关、预期 Body 关节数组成，不固化 Maya 命名空间。文件采用版本化 JSON 和内容摘要，保存时不覆盖同名文件；读取后仍需针对实际动捕源和 Body 执行 `InspectMocapBodyMapping`，由其检查根关节、拓扑与动画通道。`maya_mocap_mapping_smoke.py` 在 30 关节 Body 和 `TakeA` 命名空间动捕源上确认保存重读后的五项解析计划完全相同。

```python
from adv_py.application import InspectMocapBodyMapping, load_mocap_mapping_preset

preset = load_mocap_mapping_preset(r"D:\mocap\human.json")
plan = InspectMocapBodyMapping(host).execute(
    "|TakeA:Hips", preset.mappings,
    expected_body_joint_count=preset.expected_body_joint_count,
).require_valid()
```

外部 FBX 不直接导入当前角色场景。`ImportMocapFbx` 先在独立后台 Maya 进程中读取 FBX，把单根关节骨架、直接动画曲线、场景单位、切线类型与角度、加权切线参数、曲线循环设置，以及关键帧和相邻关键帧中点的世界矩阵写成受限片段；主场景校验片段后在新命名空间重建关节与曲线，并在采样时刻比对世界矩阵。文件解析失败不会改变当前场景；场景写入失败会回滚，成功写入可以单次撤销和重做。

```python
from adv_py.adapters import MayaMocapClipHost
from adv_py.application import ImportMocapFbx

imported = ImportMocapFbx(MayaMocapClipHost()).apply(
    r"D:\mocap\take_01.fbx", namespace="Take01",
)
source_root = imported.snapshot.root
```

`maya_body_fbx_export_smoke.py` 将自生成 FBX 作为外部动捕导入，验证 31 关节的关键帧及帧间中点姿态，另验证失败注入、单次撤销、此前撤销历史、重做与保存重开。`maya_long_mocap_fbx_smoke.py` 对 1101 键单关节 FBX 验证整条曲线保留，并将世界姿态验收均匀限定为 2000 个时刻，覆盖首尾与帧间。当前入口只接受单根骨架和直接连接的原生时间动画曲线；对约束驱动、多根骨架、复杂 FBX 层与长片段的多关节规模仍需单独验收。

角色根部动捕可通过 `RetargetMocapRootToCharacter` 写入已登记角色的 Global 控制器。校准帧记录来源根关节世界矩阵；每个采样帧取其相对校准帧的刚体变化，把同一变化应用到该帧角色原有根部姿态，并求出 Global 控制器的六个平移、旋转通道。来源和目标无需处于相同世界位置；原有其他控制器曲线保持不变。输入必须是经过关节来源审计的动画骨架，采样区间须落在来源键值范围内。这个入口仅写入根部；脊柱使用下述组合入口，四肢仍待开发。

```python
from adv_py.adapters import MayaMocapControlHost
from adv_py.application import RetargetMocapRootToCharacter

samples = RetargetMocapRootToCharacter(MayaMocapControlHost()).apply(
    "|TakeA:Hips", start_frame=1, end_frame=10, sample_by=1,
)
```

`maya_mocap_control_root_smoke.py` 在自生成角色和动捕源上验证 10 帧 Body 根部世界矩阵、六条可编辑控制曲线、已有全局与躯干动画下的其他控制通道不变、失败回滚、单次撤销重做与保存重开。`maya_mocap_control_namespace_smoke.py` 在同场两个角色上验证只修改指定命名空间的角色。

标准双段脊柱可用 `RetargetMocapSpineToCharacter` 一次写入根部与 Spine FK 控制曲线。来源须明确指定根、脊柱、胸部三段直接父子链；校准帧上的来源局部旋转作为零点，各采样帧的局部旋转变化叠加到角色原有 FK 脊柱姿态。写入要求采样帧处于 Spine FK 模式；IK 或混合姿态尚需单独求解。当前入口支持标准双段 Spine，曲线脊柱及四肢尚未纳入。

```python
from adv_py.application import RetargetMocapSpineToCharacter

root_samples, spine_samples = RetargetMocapSpineToCharacter(MayaMocapControlHost()).apply(
    "|TakeA:Hips", source_spine="Spine", source_chest="Chest",
    start_frame=1, end_frame=10,
)
```

`maya_mocap_control_spine_smoke.py` 验证三关节来源、10 帧 Global 与两个 Spine FK 控制、已有 FK 动画叠加、Body 世界矩阵、其他通道不变、故障回滚、单次撤销重做及保存重开。

引擎骨名由 `BodyFbxNamingProfile` 指定。映射项左侧是 Body 关节短名，右侧是 FBX 中的发布名；没有列出的关节沿用 Body 短名。Root Motion 节点使用单独的 `root_name`。名称必须可移植且在整棵发布骨架中唯一；不存在的来源关节和命名冲突会在写文件前拒绝。

```python
from pathlib import Path
from adv_py.application import ExportBodyFbx
from adv_py.core import BodyFbxNamingProfile

naming = BodyFbxNamingProfile(
    root_name="EngineRoot",
    joint_names=(("Root_M", "pelvis"), ("Spine1_M", "spine_01"), ("Head_M", "head")),
)
result = ExportBodyFbx(host).apply(
    Path(r"D:\publish\character.fbx"),
    start_frame=1,
    end_frame=5,
    naming_profile=naming,
)
```

`maya_body_fbx_export_smoke.py` 使用自生成 30 关节 Body 导出三份 FBX，其中第三份应用引擎骨名 Profile；重新在空 Maya 场景导入后得到 `EngineRoot|pelvis|spine_01`、一个 `head` 关节和 31 个总关节。现有 MoCap 流程尚未直接驱动角色控制 Rig；发布曲线策略仍需单独实现与验收。
