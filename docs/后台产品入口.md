# 后台产品入口

`adv-rig` 是 Maya 2024 standalone 的命令行入口。每次命令在独立进程中打开一个现有 `.ma` 或 `.mb` 场景；写入命令只生成新的 `.ma` 文件，不覆盖输入或已有输出。场景修改由 application 用例完成，入口负责文件读写、角色选择及进度／错误报告。根命名空间使用 `--namespace :`，其他角色使用 `characters` 返回的命名空间。

```powershell
$env:PYTHONPATH = 'src'
& 'C:\Program Files\Autodesk\Maya2024\bin\mayapy.exe' -m adv_py.product `
  characters validation\results\maya2024-face-performance.ma
```

自生成双目标测试场景中的一条角色记录形如：

```json
{
  "namespace": "hero",
  "name": "AdvPy_CharacterRegistry",
  "writable": true,
  "joint_count": 72,
  "channel_count": 274,
  "face_control": "|Root_M|Spine1_M|Spine2_M|Spine3_M|Chest_M|Neck_M|Head_M|AdvPy_FaceControls"
}
```

`face-target` 接收明确的中性网格、目标路径、语义类别及顶点标记文档。下面的标记将第 3 个顶点沿对象空间 Y/Z 轴移动 `0.2/0.1`，半径 `1.0` 内的其他顶点受平滑衰减影响：

```json
{"landmarks":[{"vertex":3,"displacement":[0.0,0.2,0.1],"radius":1.0}]}
```

```powershell
& 'C:\Program Files\Autodesk\Maya2024\bin\mayapy.exe' -m adv_py.product `
  face-target input.ma --namespace hero --neutral '|FaceNeutral' `
  --name blink_L --kind expression --target '|BlinkTarget' `
  --landmarks blink-landmarks.json --output with-blink.ma
```

`face-animation` 接收 `face_performance_to_json` 生成的带摘要动画文档。`--control` 取 `characters` 返回的逻辑路径；文档时间单位必须与场景相同，通道须属于面部清单。

```powershell
& 'C:\Program Files\Autodesk\Maya2024\bin\mayapy.exe' -m adv_py.product `
  face-animation with-blink.ma --namespace hero `
  --control '|Root_M|Spine1_M|Spine2_M|Spine3_M|Chest_M|Neck_M|Head_M|AdvPy_FaceControls' `
  --clip mouth.json --output animated.ma
```

成功结果以 JSON 写到标准输出；场景打开、资产生成、动画应用和保存进度以 JSON 事件写到标准错误输出。预检或写入失败返回退出码 `2` 与错误事件，不生成输出场景。`characters` 会列出发现但不可写的登记及原因；引用角色仍按 application 合同拒绝修改。

全身姿态与动画使用已有的路径无关文档合同。`pose-capture` 从当前帧或显式 `--frame` 捕获控制值、空间状态和 Body 参考；`pose-apply` 检查角色兼容摘要，恢复控制、空间和实际身体姿态。静态姿态不能写到已有动画输入的控制通道。

```powershell
& 'C:\Program Files\Autodesk\Maya2024\bin\mayapy.exe' -m adv_py.product `
  pose-capture input.ma --namespace : --frame 1 --output current.pose.json
& 'C:\Program Files\Autodesk\Maya2024\bin\mayapy.exe' -m adv_py.product `
  pose-apply input.ma --namespace : --pose target.pose.json --output posed.ma
```

`animation-capture` 按整数帧范围采样完整角色，`animation-apply` 在一个可撤销事务中写回文档；时间单位、通道、角色兼容性、片段外旧键和结果姿态由 application 层校验。

```powershell
& 'C:\Program Files\Autodesk\Maya2024\bin\mayapy.exe' -m adv_py.product `
  animation-capture animated.ma --namespace : --start 1 --end 21 --step 5 `
  --output captured.animation.json
& 'C:\Program Files\Autodesk\Maya2024\bin\mayapy.exe' -m adv_py.product `
  animation-apply animated.ma --namespace : --clip captured.animation.json `
  --output restored.ma
```

`presets` 扫描目录下最多 256 个 JSON 文件，分别报告格式、与当前角色的布局兼容性及当前场景是否可写。未识别文件和损坏文档会带原因列出，不阻断其他预设的检查。

```powershell
& 'C:\Program Files\Autodesk\Maya2024\bin\mayapy.exe' -m adv_py.product `
  presets input.ma --namespace : --directory presets
```

独立进程验收从一份已登记的 72 关节测试场景出发，验证角色发现、目标生成、输出文件防覆盖、时间单位错误拒绝、口型写入，以及新进程重开后的目标来源、角色登记和关键帧读回。验收命令见 `validation/product_entry_smoke.py`。

身体入口另以自生成 30 关节角色验证：已扰动角色从目标 Pose 恢复后，独立进程读回的完整姿态误差小于 `1e-4`；五帧动画片段捕获、应用与重开后的采样误差为 `0`；错误兼容摘要拒绝写出，输入场景字节不变。验收命令见 `validation/product_body_entry_smoke.py`。
