# v0.95 README 与发布收口

`v0.95.0` 不增加新的绑定能力。本版本整理 `v0.94.0` 已完成的 Maya-first 结果，并把仓库首页收口为面向使用者和技术评审的发布入口。

## 本版本变更

- 重写中文 README，第一屏说明项目用途、开发顺序、验证环境和当前完成状态；
- 增加稳定的仓库内架构展示图；
- 将实现长清单收束为 Fit / Body、角色控制与蒙皮、动画与导出三组工作流；
- 补全安装、MEL 清单、纯 Python 回归和 Maya MoCap 验证的最短命令；
- 明确私有仓库、授权源码、Blender 第二阶段和当前未包含能力的边界；
- 将包版本统一到 `0.95.0`。

## 沿用的验证基线

- 272 项纯 Python 回归测试；
- Maya 2024 standalone；
- 30 关节基础 Body、70 关节五指 Body、31 关节独立导出骨架；
- 当前 MoCap 验证记录包含 5 个临时约束、姿态保持、跨帧响应、显式断开、两级 Undo、选择与时间恢复，状态为 `passed`。

宿主 smoke 结果由 `validation/` 中的脚本和本机 `validation/results/` JSON 记录组成。结果文件包含运行环境与 PID，不作为公开发布资产提交。

## 后续顺序

后续恢复开发时仍按 Maya-first 推进。最近候选纵切是显式 MoCap 采样与 bake；Blender 第二阶段在 Maya 合同稳定前保持冻结。
