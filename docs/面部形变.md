# 面部形变

当前面部模块以已登记角色的 `Head_M` 为控制归属，以显式中性网格和目标网格作为形状输入。一个目标对应一个 `0–1` 控制属性和一个 BlendShape 权重；目标标记为 `expression`（表情）或 `viseme`（口型）。目标网格不从名称推断类别。

目标网格可以从现成雕刻网格提供，也可以由中性网格上的稀疏标记生成。标记由顶点编号、对象空间位移和作用半径组成；标记顶点严格取给定位移，附近顶点按距离平滑衰减，半径外不改变。生成网格保留原面连接顺序和顶点编号，写入锁定的来源记录，包含中性网格的拓扑／位置摘要、通道类别及全部标记参数。

```python
from adv_py.application import GenerateFaceTarget
from adv_py.core import FaceLandmark

smile_target = FaceTarget("smile_R", FaceShapeKind.EXPRESSION, "|SmileTarget")
recipe = GenerateFaceTarget(host).apply(
    "|FaceNeutral", smile_target,
    (FaceLandmark(vertex=0, displacement=(0.5, 0.0, 0.2), radius=0.25),),
)
```

生成是一次 Maya Undo 事务；失败回滚，重做在原角色命名空间恢复网格、顶点和来源记录。`GenerateFaceTarget(host).audit(recipe)` 可在保存重开或角色重建后复核资产。来源记录只描述生成时的几何，不自动追踪之后的手工雕刻。

已有雕刻目标可导出为版本化稀疏位移资产。文档保存目标语义、顶点数、面连接摘要、中性网格位置摘要、发生变化的顶点编号和 XYZ 位移，并以 SHA-256 摘要校验内容；不保存 Maya DAG 路径。普通导入先核对目标角色的中性网格拓扑和全部基准顶点位置，再重建目标 mesh，写入来源摘要。位置不一致即拒绝，不隐式缩放。

```python
from pathlib import Path
from adv_py.application import (
    ExportFaceTargetAsset, ImportFaceTargetAsset,
    load_face_target_asset, save_face_target_asset,
)

asset = ExportFaceTargetAsset(host).execute("|FaceNeutral", smile_target)
save_face_target_asset(asset, Path("smile.asset.json"))

# 在另一份具有相同中性网格的角色场景中：
imported = ImportFaceTargetAsset(other_host).apply(
    "|FaceNeutral", load_face_target_asset(Path("smile.asset.json")),
    "|ImportedSmile",
)
```

资产文件采用创建新文件且拒绝覆盖的原子写出。Maya 2024 后台验收包含四个变化顶点的完整导出／导入、新进程重开后的几何对比、导入目标驱动 BlendShape、基准位置不匹配拒绝、失败回滚和撤销重做。

源、目标中性网格拓扑不同时，可显式执行近邻表面转移。源网格由 Maya 的实际三角化结果提供；每个目标顶点在源表面找到最近点，按该三角形的重心权重插值稀疏雕刻位移，并生成绑定目标拓扑及目标中性位置摘要的新资产。三角面通过空间树查找。调用方必须指定对象空间的 `max_distance`：任一目标顶点离源表面超过此值即拒绝整次转移，不写资产。默认要求对象空间坐标已对齐；网格只有刚体位置或朝向差异时，可提供三个不共线的源／目标顶点对应建立显式对齐，查询位置和雕刻位移都会转换到对应坐标系。标记点不满足刚体误差上限时拒绝；不进行尺度缩放或自动语义配准。

```python
from adv_py.application import TransferFaceTargetAsset, save_face_target_asset

plan = TransferFaceTargetAsset(host).execute(
    "|FaceNeutral", "|FaceNeutralDense", asset,
    max_distance=0.001,
)
save_face_target_asset(plan.result.asset, Path("smile.dense.asset.json"))
```

跨场景时，先从源角色导出中性几何文档；版本 2 文档保存源网格顶点、实际三角面、场景向上轴和长度单位、拓扑／位置摘要及整体内容摘要。目标角色场景只需保留目标中性网格，不需要复制源网格。读取会校验文档摘要和源网格位置摘要，雕刻资产还会独立核对源拓扑及源位置摘要。源、目标场景的向上轴或长度单位不同则拒绝；旧版无单位文档需在源场景重新导出。

显式刚体对齐文件示例：`{"pairs":[[0,4],[1,7],[2,1]],"max_residual":0.001}`。每一对依次为源顶点索引和目标顶点索引，三个点必须互不重复且不共线；`max_residual` 与场景长度单位一致。执行 `face-asset-transfer` 时通过 `--alignment 对齐文件.json` 指定。仅适用于两套网格形状、尺度一致而对象空间位置或朝向不同的情况。

```python
from adv_py.application import (ExportFaceNeutralGeometry,
    save_face_neutral_geometry, load_face_neutral_geometry)

source_geometry = ExportFaceNeutralGeometry(source_host).execute("|FaceNeutral")
save_face_neutral_geometry(source_geometry, Path("face-source.geometry.json"))

# 在另一份角色场景中：
source_geometry = load_face_neutral_geometry(Path("face-source.geometry.json"))
plan = TransferFaceTargetAsset(target_host).execute_from_geometry(
    source_geometry, "|FaceNeutralDense", asset, max_distance=0.001)
```

自生成 4 顶点平面雕刻转移到 9 顶点细分网格后，在新 Maya 进程导入目标，逐顶点最大位置误差为 `5.96e-8`；目标驱动 BlendShape 的最大位移为 `0.5`。目标场景不含源中性网格时，几何文档链路得到相同结果。另一个 5 顶点目标网格经旋转、平移和显式三点对齐后，导入位置误差为 `2.38e-7`，BlendShape 最大位移为 `0.5`。距离源表面较远的目标、摘要被修改的几何文档和声明长度单位不匹配的文档均被拒绝。最近表面策略适合表面对应明确的网格；贴近的内外表面、唇缘或复杂拓扑可能需要显式语义对应或人工校对，当前尚无这类自动保障。

多个资产版本可登记在追加式目录中。`objects/` 以文件内容 SHA-256 寻址，`refs/<通道>/<版本>.json` 保存通道、类别、语义版本和对象摘要；引用和对象均以创建新文件的方式发布。重复登记相同内容可复用，已有版本指向不同内容时拒绝；损坏的引用或对象在列目录时显式标记为无效，并拒绝解析。版本写作 `主.次.修订`，例如 `1.0.0`。

```python
from adv_py.application import FaceAssetLibrary

library = FaceAssetLibrary(Path("face-library"))
library.add(asset, "1.0.0")
versions = library.list()
same_asset = library.resolve("smile_R", "1.0.0")
```

三个版本共享同一通道类别、顶点顺序和中性网格位置摘要时，可明确指定共同基线，将左右两个雕刻分支合并。对每个顶点分别比较基线和两分支：只有一边改变时采用该边；两边改成相同位移时采用共同结果；两边对同一顶点作出不同改动时拒绝，并报告冲突顶点索引。删除原位移也视为改动。不会自动平均冲突位移，且空目标资产不能登记。跨拓扑或不同中性网格基准仍拒绝直接合并；需要先把资产分别转到同一目标基准，再检查转移结果。

```python
merged = library.merge("smile_R", "1.0.0", "1.1.0", "1.2.0", "2.0.0")
asset = library.resolve("smile_R", merged.release)
```

合并结果以新版本发布，不改写三个来源版本。新引用采用版本 2，记录 `base`、`left`、`right` 的版本号和对象摘要；读取时复核来源引用和对象，来源损坏会让合并版本显式失效。普通登记仍用版本 1 引用，旧目录可继续读取。自生成面部资产已通过跨进程合并、导出、Maya 场景导入及重开后的逐顶点几何复核。

```python
from adv_py.adapters import MayaFaceHost
from adv_py.application import BuildFaceBlendShapes
from adv_py.core import FaceShapeKind, FaceTarget

host = MayaFaceHost(namespace="hero")
result = BuildFaceBlendShapes(host).apply(
    "|FaceNeutral",
    (
        FaceTarget("smile_R", FaceShapeKind.EXPRESSION, "|SmileTarget"),
        FaceTarget("viseme_A", FaceShapeKind.VISEME, "|VisemeATarget"),
    ),
)
```

`|FaceNeutral` 和两个目标是角色命名空间中的实际 mesh transform。中性网格与目标必须有相同的顶点数量和面连接顺序；每个目标至少有一个顶点相对中性网格发生有效位移。构建前记录完整点位置和拓扑摘要，执行前再捕获一次，拒绝输入漂移、重复语义名称、相同目标网格及已有面部控制／变形器名称。

构建在一个 Maya Undo 事务中创建 `Head_M|AdvPy_FaceControls`，为两个语义通道建立可写键的属性，再创建位于 Skin 前的 `AdvPy_FaceBlendShape`。控制属性直接连接对应权重；控制节点记录 schema 版本和目标类别清单。目标网格保留为调用方资产，构建过程不删除它们。事务后复检属性、alias、连接和实际网格位移。构建失败回滚新增节点，原角色和目标网格保持可用。

Maya 2024 后台验收使用自行生成的 72 关节角色、四顶点面部网格、一个表情目标和一个口型目标。最大实际顶点位移为 `0.5`；两条控制动画在保存重开后可读。以控制根作为显式用户附件进行同布局角色重建时，控制节点和 BlendShape 的 UUID、连接及网格形变均保留；构建失败回滚、单次 Undo 和 Redo 也通过。

面部时间片段使用每帧一组完整通道权重，权重范围为 `0–1`，通道顺序与控制节点的语义清单完全一致。时间单位必须等于当前 Maya 场景单位。文档含格式版本和内容摘要，读取时拒绝重复通道、重复或倒序帧、缺项、越界权重及内容篡改。

```python
from adv_py.application import ApplyFacePerformance
from adv_py.core import FacePerformance

clip = FacePerformance(
    (("smile_R", FaceShapeKind.EXPRESSION),
     ("viseme_A", FaceShapeKind.VISEME)),
    "film",
    ((1, (0.0, 0.0)), (5, (1.0, 0.4)), (10, (0.2, 1.0))),
)
ApplyFacePerformance(host).apply(result.plan.control_path, clip)
```

写入前检查角色归属、现有动画驱动、可写性与时间单位。写入时在片段两侧补保护帧，片段外原有关键帧的数值和切线保持不变；两个通道作为一次 Maya Undo 事务提交。故障回滚、单次撤销重做、保存重开、重建后的控制与实际形变均在后台场景验收通过。该片段是已知帧权重的载体，不负责从语音自动识别音素。

已有逐个音素的时间标注时，可将标签映射到角色已有口型目标。`PhonemeCue` 的区间为 `[start, end)`；相邻音素在边界两侧按指定帧数平滑交接，停顿处权重回到零。生成的片段只包含被用到的 `viseme` 通道，写入时不会改动表情属性及其动画。

```python
from adv_py.core import PhonemeCue, phoneme_cues_to_performance

mouth = phoneme_cues_to_performance(
    (("smile_R", FaceShapeKind.EXPRESSION),
     ("viseme_A", FaceShapeKind.VISEME)),
    "film",
    (PhonemeCue("a", 30, 36),),
    (("a", "viseme_A"),),
    transition_frames=2,
)
ApplyFacePerformance(host).apply(result.plan.control_path, mouth)
```

音素标签和起止帧来自外部标注；这里不含语音识别。映射显式指定角色目标，不按目标名称猜测发音。重叠的输入区间、未映射标签和非口型目标会被拒绝。过渡段允许相邻口型同时激活，并将总权重限制在 `1` 以内。

当前的标记必须由用户指定顶点位移及半径，尚不从照片、扫描或现成拓扑自动定位解剖 landmark；跨拓扑支持对象空间已对齐的近邻表面转移和跨场景源几何文档，尚未提供语义 landmark 对应、自动网格配准、眼睑／下颌骨骼、表情组合规则或自动语音识别。面部控制作为显式用户附件参与重建，尚未纳入角色登记的标准控制通道与通用 Pose／动画文档。
