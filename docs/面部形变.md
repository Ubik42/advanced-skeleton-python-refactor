# 面部形变

当前面部模块以已登记角色的 `Head_M` 为控制归属，以显式中性网格和目标网格作为拟合后的形状输入。一个目标对应一个 `0–1` 控制属性和一个 BlendShape 权重；目标标记为 `expression`（表情）或 `viseme`（口型）。目标网格不从名称推断类别。

```python
from adv_py.adapters import MayaFaceHost
from adv_py.application import BuildFaceBlendShapes
from adv_py.core import FaceShapeKind, FaceTarget

host = MayaFaceHost(namespace="hero")
result = BuildFaceBlendShapes(host).apply(
    "|FaceNeutral",
    (
        FaceTarget("smile_R", FaceShapeKind.EXPRESSION, "|SmileTarget"),
        FaceTarget("viseme_A", FaceShapeKind.VISEME, "|VisemeATarget"),
    ),
)
```

`|FaceNeutral` 和两个目标是角色命名空间中的实际 mesh transform。中性网格与目标必须有相同的顶点数量和面连接顺序；每个目标至少有一个顶点相对中性网格发生有效位移。构建前记录完整点位置和拓扑摘要，执行前再捕获一次，拒绝输入漂移、重复语义名称、相同目标网格及已有面部控制／变形器名称。

构建在一个 Maya Undo 事务中创建 `Head_M|AdvPy_FaceControls`，为两个语义通道建立可写键的属性，再创建位于 Skin 前的 `AdvPy_FaceBlendShape`。控制属性直接连接对应权重；控制节点记录 schema 版本和目标类别清单。目标网格保留为调用方资产，构建过程不删除它们。事务后复检属性、alias、连接和实际网格位移。构建失败回滚新增节点，原角色和目标网格保持可用。

Maya 2024 后台验收使用自行生成的 72 关节角色、四顶点面部网格、一个表情目标和一个口型目标。最大实际顶点位移为 `0.5`；两条控制动画在保存重开后可读。以控制根作为显式用户附件进行同布局角色重建时，控制节点和 BlendShape 的 UUID、连接及网格形变均保留；构建失败回滚、单次 Undo 和 Redo 也通过。

当前目标网格须预先制作，尚不提供 landmark 自动拟合、眼睑／下颌骨骼、表情组合规则、音素到时间曲线的生成或外部目标资产生命周期管理。面部控制作为显式用户附件参与重建，尚未纳入角色登记的标准控制通道与通用 Pose／动画文档。
