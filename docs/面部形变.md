# 面部形变

当前面部模块以已登记角色的 `Head_M` 为控制归属，以显式中性网格和目标网格作为形状输入。一个目标对应一个 `0–1` 控制属性和一个 BlendShape 权重；目标标记为 `expression`（表情）或 `viseme`（口型）。目标网格不从名称推断类别。

目标网格可以从现成雕刻网格提供，也可以由中性网格上的稀疏标记生成。标记由顶点编号、对象空间位移和作用半径组成；标记顶点严格取给定位移，附近顶点按距离平滑衰减，半径外不改变。生成网格保留原面连接顺序和顶点编号，写入锁定的来源记录，包含中性网格的拓扑／位置摘要、通道类别及全部标记参数。

```python
from adv_py.application import GenerateFaceTarget
from adv_py.core import FaceLandmark

smile_target = FaceTarget("smile_R", FaceShapeKind.EXPRESSION, "|SmileTarget")
recipe = GenerateFaceTarget(host).apply(
    "|FaceNeutral", smile_target,
    (FaceLandmark(vertex=0, displacement=(0.5, 0.0, 0.2), radius=0.25),),
)
```

生成是一次 Maya Undo 事务；失败回滚，重做在原角色命名空间恢复网格、顶点和来源记录。`GenerateFaceTarget(host).audit(recipe)` 可在保存重开或角色重建后复核资产。来源记录只描述生成时的几何，不自动追踪之后的手工雕刻。

已有雕刻目标可导出为版本化稀疏位移资产。文档保存目标语义、顶点数、面连接摘要、中性网格位置摘要、发生变化的顶点编号和 XYZ 位移，并以 SHA-256 摘要校验内容；不保存 Maya DAG 路径。导入时先核对目标角色的中性网格拓扑和全部基准顶点位置，再重建目标 mesh，写入来源摘要。位置不一致即拒绝，不隐式缩放或跨拓扑映射。

```python
from pathlib import Path
from adv_py.application import (
    ExportFaceTargetAsset, ImportFaceTargetAsset,
    load_face_target_asset, save_face_target_asset,
)

asset = ExportFaceTargetAsset(host).execute("|FaceNeutral", smile_target)
save_face_target_asset(asset, Path("smile.asset.json"))

# 在另一份具有相同中性网格的角色场景中：
imported = ImportFaceTargetAsset(other_host).apply(
    "|FaceNeutral", load_face_target_asset(Path("smile.asset.json")),
    "|ImportedSmile",
)
```

资产文件采用创建新文件且拒绝覆盖的原子写出。Maya 2024 后台验收包含四个变化顶点的完整导出／导入、新进程重开后的几何对比、导入目标驱动 BlendShape、基准位置不匹配拒绝、失败回滚和撤销重做。此格式解决显式雕刻目标的跨场景携带；尚未提供资产目录版本选择、冲突合并或拓扑迁移。

```python
from adv_py.adapters import MayaFaceHost
from adv_py.application import BuildFaceBlendShapes
from adv_py.core import FaceShapeKind, FaceTarget

host = MayaFaceHost(namespace="hero")
result = BuildFaceBlendShapes(host).apply(
    "|FaceNeutral",
    (
        FaceTarget("smile_R", FaceShapeKind.EXPRESSION, "|SmileTarget"),
        FaceTarget("viseme_A", FaceShapeKind.VISEME, "|VisemeATarget"),
    ),
)
```

`|FaceNeutral` 和两个目标是角色命名空间中的实际 mesh transform。中性网格与目标必须有相同的顶点数量和面连接顺序；每个目标至少有一个顶点相对中性网格发生有效位移。构建前记录完整点位置和拓扑摘要，执行前再捕获一次，拒绝输入漂移、重复语义名称、相同目标网格及已有面部控制／变形器名称。

构建在一个 Maya Undo 事务中创建 `Head_M|AdvPy_FaceControls`，为两个语义通道建立可写键的属性，再创建位于 Skin 前的 `AdvPy_FaceBlendShape`。控制属性直接连接对应权重；控制节点记录 schema 版本和目标类别清单。目标网格保留为调用方资产，构建过程不删除它们。事务后复检属性、alias、连接和实际网格位移。构建失败回滚新增节点，原角色和目标网格保持可用。

Maya 2024 后台验收使用自行生成的 72 关节角色、四顶点面部网格、一个表情目标和一个口型目标。最大实际顶点位移为 `0.5`；两条控制动画在保存重开后可读。以控制根作为显式用户附件进行同布局角色重建时，控制节点和 BlendShape 的 UUID、连接及网格形变均保留；构建失败回滚、单次 Undo 和 Redo 也通过。

面部时间片段使用每帧一组完整通道权重，权重范围为 `0–1`，通道顺序与控制节点的语义清单完全一致。时间单位必须等于当前 Maya 场景单位。文档含格式版本和内容摘要，读取时拒绝重复通道、重复或倒序帧、缺项、越界权重及内容篡改。

```python
from adv_py.application import ApplyFacePerformance
from adv_py.core import FacePerformance

clip = FacePerformance(
    (("smile_R", FaceShapeKind.EXPRESSION),
     ("viseme_A", FaceShapeKind.VISEME)),
    "film",
    ((1, (0.0, 0.0)), (5, (1.0, 0.4)), (10, (0.2, 1.0))),
)
ApplyFacePerformance(host).apply(result.plan.control_path, clip)
```

写入前检查角色归属、现有动画驱动、可写性与时间单位。写入时在片段两侧补保护帧，片段外原有关键帧的数值和切线保持不变；两个通道作为一次 Maya Undo 事务提交。故障回滚、单次撤销重做、保存重开、重建后的控制与实际形变均在后台场景验收通过。该片段是已知帧权重的载体，不负责从语音自动识别音素。

已有逐个音素的时间标注时，可将标签映射到角色已有口型目标。`PhonemeCue` 的区间为 `[start, end)`；相邻音素在边界两侧按指定帧数平滑交接，停顿处权重回到零。生成的片段只包含被用到的 `viseme` 通道，写入时不会改动表情属性及其动画。

```python
from adv_py.core import PhonemeCue, phoneme_cues_to_performance

mouth = phoneme_cues_to_performance(
    (("smile_R", FaceShapeKind.EXPRESSION),
     ("viseme_A", FaceShapeKind.VISEME)),
    "film",
    (PhonemeCue("a", 30, 36),),
    (("a", "viseme_A"),),
    transition_frames=2,
)
ApplyFacePerformance(host).apply(result.plan.control_path, mouth)
```

音素标签和起止帧来自外部标注；这里不含语音识别。映射显式指定角色目标，不按目标名称猜测发音。重叠的输入区间、未映射标签和非口型目标会被拒绝。过渡段允许相邻口型同时激活，并将总权重限制在 `1` 以内。

当前的标记必须由用户指定顶点位移及半径，尚不从照片、扫描或现成拓扑自动定位解剖 landmark；也未提供跨拓扑目标转移、眼睑／下颌骨骼、表情组合规则、自动语音识别或外部雕刻资产目录管理。面部控制作为显式用户附件参与重建，尚未纳入角色登记的标准控制通道与通用 Pose／动画文档。
