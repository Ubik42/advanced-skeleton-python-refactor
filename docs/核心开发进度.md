## 完成边界

脊柱使用固定长度双段 RP IK。完全伸直匹配时，IK 目标沿伸展方向外移总长度的 `1e-5`，让 Maya 求解器落在最大伸展位置；Body 姿态仍以同一阈值读回复检，不放宽标准。完全折叠导致起止点重合时，无法确定 bend plane，当前拒绝匹配。

匹配只作用当前姿态，不写关键帧；目标已有动画输入、锁定、引用、动画层、非等比 / 反射缩放和部分混合值会被拒绝。标准场景角度单位为 degree。尚不支持脊柱拉伸、任意脊椎数量或旧角色自动改造。

空间切换重建本工具拥有的单源约束，保留当前帧 offset 的世界姿态；约束上的动画 / 外部输入、外部消费、目标锁定等在写入前拒绝。该操作不写动画键，也不保持其他帧的历史运动。

代理网格只验证完整控制与显式蒙皮链路，不代表生产角色表面、自动高质量权重或真实资产适配。当前里程碑不包含动画区间空间切换、任意数量脊椎、Blender、Face、UI 或外部工具扩展。
