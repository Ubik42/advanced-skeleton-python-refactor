# 拉伸与体积动画匹配

## 功能

`EnableBodyCharacterStretchMatching` 为已启用四肢动画的角色增加显式 IK 段长覆盖和体积匹配。`BakeBodyCharacterLimbMode` 随后可转换弯曲且拉伸的臂腿动画，并保持身体与辅助变形骨骼在采样帧的世界姿态。

自动拉伸由起点到末端目标的距离求比例；同一末端位置可以对应不同的上下段长度和弯曲程度。因此 FK→IK 不能只移动末端和 Pole。匹配时分别计算两段本地长度，写入覆盖层，再执行原有 IK 求解和朝向补偿。volume 作用于 twist helper 的横截面；转换还需要恢复这些辅助骨骼的缩放。

## 新增数据

在已有 189 / 293 通道上增加 16 个通道，完整角色为 205 / 309 通道。

| 每侧数据 | 数量 | 含义 |
| --- | --- | --- |
| `ikMatchLength0_R` / `ikMatchLength1_R` 等 | 2 | 上下段沿各自主轴的有符号本地长度，场景单位为 cm |
| `ikMatchLengthWeight_R` 等 | 1 | 0 使用既有自动拉伸输出，1 使用匹配段长 |
| `matchVolumeFactor_R` 等 | 1 | 乘在既有体积输出上的正比例，补偿模式转换引起的横截面变化 |

四组分别为 arm R / L、leg R / L。新节点初始为长度权重 0、体积因子 1，因此安装保持已有身体、机制骨骼、辅助骨骼及蒙皮。新增通道由全身姿态和动画文档保存，登记的布局兼容摘要随之更新；旧布局文档需要在对应旧布局下读取，不能直接当作新布局的完整快照。

长度换算使用目标骨段世界距离除以 IK 父级主轴的世界缩放，并保留原 IK 骨段的正负方向。例如世界距离 3.795 cm、父级缩放 1.1，对应本地长度 3.45 cm。体积补偿为“转换前辅助骨骼横截面比例 ÷ 转换后原体积网络输出”；目标比例 0.75、网络输出 0.8 时，匹配因子为 0.9375。

匹配把目标帧的长度权重写为 1。该状态表示动画使用已匹配的明确段长；需要回到自动拉伸时，应给权重写入 0 并重新确认过渡姿态。体积因子保留原体积网络的输入语义，在其输出上补偿转换结果。

## 调用

```python
from adv_py.adapters import MayaBodyBuildHost
from adv_py.application import (
    EnableBodyCharacterLimbAnimation,
    EnableBodyCharacterStretchMatching,
    BakeBodyCharacterLimbMode,
)

host = MayaBodyBuildHost()
EnableBodyCharacterLimbAnimation(host).apply()
EnableBodyCharacterStretchMatching(host).apply()
BakeBodyCharacterLimbMode(host).execute(1, 21, "arm", "R", "ik", step=1)
BakeBodyCharacterLimbMode(host).execute(1, 21, "leg", "L", "fk", step=1)
```

角色需已登记，具备标准四肢、twist helper 和 volume 网络。场景要求 cm / degree、可撤销、无动画层；源模式在采样帧必须处于 FK 或 IK 端点。两种启用用例均有只读 `plan()`，重复启用为无修改操作。

绑定轴和辅助骨骼布局从登记的绑定矩阵生成，不根据当前混合姿态猜测。因此当前时间处于动画两键之间时，登记检查仍使用稳定的结构。

## 写入与复检

覆盖层保留原拉伸输出作为输入 0，将显式段长作为输入 1。单位转换节点、原输出接线、目标关节、输入集合和输出消费者均受审计。体积补偿只连接登记的辅助骨骼缩放通道。

安装位于一笔事务中，新增成员包含 IK 驱动关节、辅助骨骼及父链；完成后比较安装前后的机制和辅助骨骼世界矩阵。错误读回会撤销节点、属性、接线和登记文档。

转换复检同时覆盖全部 Body 矩阵、控制键值以及目标侧辅助骨骼的完整世界矩阵。辅助骨骼矩阵单独检查维度、有限值和数值误差。任何部分失败，整笔写键撤销。保证范围是显式采样帧，点间仍遵循原动画片段的插值合同。

## 验收

- 311 项纯 Python 回归通过，包括旋转与缩放下的有符号长度、体积比例及退化 / 非有限输入拒绝。
- 30 / 70 关节角色的两段 FK 长度按帧增加 5%–28%，上下段比例不同；左右臂腿双向转换通过。
- 除身体代理网格外，另建 128 顶点网格，明确绑定到 16 个 twist helper。两类网格均参与逐帧比较。30 / 70 关节最大位置分量误差分别约 `1.38e-6 cm` / `1.91e-6 cm`。
- 体积因子缩小后的 IK→FK→IK 往返通过。自动手臂拉伸，以及膝盖锁定 0.6、长度偏置 0.2、脚掌滚动 0–24 度的腿部组合通过；该组合最大网格误差约 `4.30e-6 cm`。
- 安装与转换 Undo / Redo、重复调用、注入匹配失败、错误安装读回、选择与当前时间保持通过。
- 两种拓扑保存重开后可继续转换；70 关节重开最大身体矩阵元素误差约 `3.12e-7`，网格位置分量误差约 `9.54e-7 cm`。
