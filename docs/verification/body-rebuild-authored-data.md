# Body 重建的用户数据保留（2026-10-01）

依据只读 AdvancedSkeleton 6.925 `asReBuildAdvancedSkeleton`，本批继续补已有重建主链，没有增加另一套 Rig 生成器。

## 本批代码接入

- MEL 78253–78299、78390–78449：同名控制器的曲线形状允许与新建默认形状具有不同的阶数、CV 数量、结点和闭合形式。暂存保留完整齐次 CV 数据；交接使用原版 `oldShape.local → newShape.create`，强制读取结果，再随旧 Rig 删除旧形状。没有通过采样点重新拟合用户曲线。颜色、RGB 颜色、线宽及原显示设置一起保留。该原生连接与删除行为仍需 Maya 验收。
- 用户添加的多条曲线按原 UUID 移到对应新控制器，交接旧生成图的可见性及选择集连接，最后恢复原命名空间；用户删去或改名的默认曲线允许由新建默认曲线补入，与原版的同名恢复流程一致。此处只支持未由历史或 CP 输入驱动的独立 NURBS 控制形状；求解曲线继续要求原生成图相符。
- MEL 78208–78249：记录控制器 TRS 的 Lock / Hide / Channel Box 状态与已启用的变换限制，在动画及连接交接后恢复。按原版恢复已有的限制，不反向打开新生成机制的隐藏通道。
- 保存角色的校验允许控制曲线的颜色、尺寸、数量和通道锁定被用户编辑。新建阶段仍使用严格的默认规格检查；已登记角色的父链、驱动节点和连接仍需有效。
- 重建采集采用独立的只读检查，移除“必须能给全身通道写键”的错误前置要求。原生时间曲线的全部输出进入保留快照，重建不生成新关键帧。
- 原属性的当前动画值不再与新建默认值做定义相等比较。已登记动画属性仍校验原类型和范围，再交接值、曲线、显示与锁定状态；未登记的同名属性冲突仍需明确处理。
- MEL 78195–78207：ControlSet / DeformSet 中不属于 AllSet 的用户控制器或附加关节自动进入完整子树保留；不再要求普通新增控制器由用户另外填写附件列表。
- MEL 78130–78176 的用户选择集保留：用户 objectSet 保持原 UUID，重建生成成员按 UUID 换成新节点；组件成员、集的嵌套父级和未参与替换的成员一起保留，交接与原位替换后均检查。
