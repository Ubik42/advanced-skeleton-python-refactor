# 原版 Spline 对齐与切换接入

本批依据 AdvancedSkeleton 6.925 MEL 10978–11439、26401–26460 和 81077–81162。原版源码保持只读。没有启动 Maya、导入工程、执行功能测试或推送 GitHub。

## 已接入

- 原版普通 Align / Switch 独立于精确姿态拟合扩展。FK→IK 创建当前物理 Body 链的临时线性曲线，再按原参数重建为三次曲线；Hybrid 控制器先按曲线百分比和最近 Deform 的朝向对齐，IK 控制器按首、尾、中间的次序对齐。
- 最近 Deform 查询采用原版排除左侧、Partial 和 Fix 的规则，并按三位小数距离与名称排序。Part 仍参与物理曲线和最近关节查找。结束控制器及 Root 起点使用 FKX 中的绑定朝向偏移；普通中间 IK 控制器归零旋转，不覆盖 CV、拉伸、体积或 Follow 参数。
- IK→FK 包含实际起点 FK（包括 Root），各 IK 输出在修改父控制器前捕获，再按原版两次设置位置与朝向。内部 BaseFK 不冒充实际起点控制器。
- Switch 采用源模式端点检查、前一帧保护键、两次对齐、逐帧区间切换及区间结束恢复键。只写该系统 FK / IK / Hybrid 的平移、旋转及混合属性。按原版区间切换后保留 Auto Key 开启；选择和时间按原版操作收尾。
- 新建来源 Spline 的首 IK 平移和全部 IK 旋转可编辑、可登记。旧 Python 角色的首平移及缺少的中间旋转可在同一事务中升级；保存文档记录标记，同布局重建保留通道策略。非来源的历史标准 Spline 保留原布局。
- 新建来源的非 localOrient IK 控制器采用原版世界坐标朝向，localOrient 分支采用捕获的局部轴。首 Hybrid 与缩放参照读实际起点 Body 的绑定轴，避免内部求解链的首节朝向替代 Root 的原始朝向。旧保存图保留原来的朝向策略，不在通道升级中改变父空间。
- 移除来源 Spline 缩放权重与登记关节的额外 64 上限，标准历史 Spline 文档的既有限制仍保留。
- 精确姿态迁移也补起点：IK 数值拟合包含首控制器平移与首 Body；FK 匹配使用实际起点 FK 的已登记通道，完整读取 OPM 世界姿态。普通原版操作不会调用这些数值拟合函数。
- 已有跨角色脊柱迁移按实际登记的 settings 节点解析模式及控制通道，不再硬编码旧标准前缀；来源 FK 事件走原生 OPM 和 Root 匹配路径。现有跨角色迁移仅支持单一 Spline 系统，明确拒绝只处理多系统主链。
- 面板的现有动画操作区接入系统选择、独立对齐、当前帧切换及原版逐帧区间切换。

## 尚未完成

主动改变 Spline 控制器数量的新旧生成图、被删除控制器的曲线及用户附件交接仍未完成。同布局重建仍按保存数量恢复，不能把它算作数量迁移。较老 Python Spline 求解图的逐版本恢复／迁移也仍有缺口；此项是 Python 工程历史兼容，不能替代原版主体复刻。其他覆盖矩阵缺口和最终 Maya 整链验收仍待完成。

以上仅为代码接入，Maya 未验收。原版 FK→曲线 IK 本身明确允许目标不能完全对齐，因此普通操作保留原版提示，不以精确姿态迁移的收敛门槛改变原版行为。Goal 保持活跃。
