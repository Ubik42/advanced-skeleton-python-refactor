# 自定义控制器内部合同

AdvancedSkeleton 的 Skin、Cluster、SoftMod 自定义控制都从一个已绘制的 SoftMod 区域开始。SoftMod 是 Maya 的局部变形器：中心和顶点权重决定受影响的网格区域。[Skin Control](https://animationstudios.com.au/help/asSkinControlCreate.html)以新关节驱动该区域；[Cluster Control](https://animationstudios.com.au/help/asClusterControlCreate.html)使用 Cluster 变形器；[SoftMod Control](https://animationstudios.com.au/help/asSoftModControlCreate.html)保留 SoftMod 并增加可滑动的底座控制。官方说明中的默认父级是距离 SoftMod 中心最近的 DeformJoint；显式父级须属于 `DeformationSystem`。

内部输入 `SoftModRegion` 保存变形器、网格、中心、顶点总数和非零区域的逐顶点权重。例如一个 18,151 顶点身体网格上的局部区域可记录为：

```python
SoftModRegion(
    deformer="BodyBicepSoftMod",
    mesh="|Character|BodyMesh",
    center=(12.3, 115.0, 2.4),
    vertex_count=18151,
    weights=(WeightedVertex(812, 0.75), WeightedVertex(813, 1.0)),
)
```

`plan_custom_controller()` 只处理有限坐标、顶点范围、权重、名称及父关节选择。自动父级按世界空间平方距离比较，同距时按关节路径排序，以保证结果可重复。`BuildCustomController.plan()` 再通过宿主读取区域和 DeformationSystem 关节、检查节点名称和场景前置条件；`apply()` 在单个事务中写入并读回。

`ExtendSoftModController` 对应 [Add influenced object](https://animationstudios.com.au/help/asSoftModControlAddInfluencedObject.html)：输入已有 SoftMod 控制器和一件新增网格，先核对控制类型、影响集合与网格可写性，再将网格加入同一变形器的影响集合。写后以集合比较成员，不依赖 Maya 返回顺序；重复添加须在写入前拒绝。
