# 自定义控制器内部合同

Body／Face 的 Custom Controllers 栏目按原版顺序展示：SoftMod Tool → Skin／Cluster／SoftMod 创建 → Cluster 权重绘制／镜像 → 添加影响对象 → 删除控制器。操作入口已接入代码，但所有 Maya 场景行为仍待集中验收。

AdvancedSkeleton 的 Skin、Cluster、SoftMod 自定义控制都从一个已绘制的 SoftMod 区域开始。SoftMod 是 Maya 的局部变形器：中心和顶点权重决定受影响的网格区域。[Skin Control](https://animationstudios.com.au/help/asSkinControlCreate.html)以新关节驱动该区域；[Cluster Control](https://animationstudios.com.au/help/asClusterControlCreate.html)使用 Cluster 变形器；[SoftMod Control](https://animationstudios.com.au/help/asSoftModControlCreate.html)保留 SoftMod 并增加可滑动的底座控制。官方说明中的默认父级是距离 SoftMod 中心最近的 DeformJoint；显式父级须属于 `DeformationSystem`。

内部输入 `SoftModRegion` 保存源操作柄、变形器、网格、中心、衰减半径／模式／曲线，以及顶点总数和完整权重遮罩。权重遮罩是 SoftMod 节点存储的逐顶点系数，不等于半径与曲线共同产生的最终位移。例如一个三顶点局部网格可记录为：

```python
SoftModRegion(
    deformer="BodyBicepSoftMod",
    mesh="|Character|BodyMesh",
    center=(12.3, 115.0, 2.4),
    vertex_count=3,
    weights=(WeightedVertex(0, 0.0), WeightedVertex(1, 0.75),
             WeightedVertex(2, 1.0)),
    source_handle="|BodyBicepSoftModHandle",
    falloff_radius=8.0,
    falloff_mode=0,
    falloff_curve=((1.0, 0.0, 3), (0.0, 1.0, 3)),
)
```

`plan_custom_controller()` 处理有限坐标、顶点范围、权重、原版名称及父关节选择。名称输入不含下划线，例如 `Bicep`；中心 X 为正生成 `Bicep_L`，否则生成 `Bicep_R`，选中 middle 时生成 `Bicep_M` 并将衰减中心的 X 设为零。局部朝向选项决定附着层是否先与父关节对齐。自动父级按世界空间平方距离比较，同距时按关节路径排序，以保证结果可重复。`BuildCustomController.plan()` 再通过宿主读取区域和 DeformationSystem 关节、检查节点名称和场景前置条件；`apply()` 在单个事务中写入并读回。

`ExtendSoftModController` 对应 [Add influenced object](https://animationstudios.com.au/help/asSoftModControlAddInfluencedObject.html)：输入已有自定义控制器和一件新增网格，先核对控制类型、影响集合与网格可写性。SoftMod／Cluster 将网格加入变形器，Skin 将控制关节加入目标网格的 SkinCluster，必要时新建 SkinCluster。写后以集合比较成员，不依赖 Maya 返回顺序；重复添加须在写入前拒绝。

原版 `asConvertSoftModToCustomControl` 的 SoftMod 分支是转换：从源节点读取衰减设置，创建新的 SoftMod、控制球和可移动底座；底座定位器驱动衰减中心，控制球通过矩阵节点驱动变形，结束时删除源操作柄。当前 CUSTOM-03 的 Maya 适配器按这个节点关系创建新变形器，并把完整遮罩写入新节点。CUSTOM-06 对 SoftMod／Cluster 使用 `geometry` 编辑命令；对 Skin Control 则将控制关节加入目标网格的 SkinCluster，目标网格没有 SkinCluster 时新建一个。两项均已接入 Body／Face 栏目，但没有运行真实 Maya；构建姿态重定位、自动镜像、50% Partial Parent 与控制外观仍有差距。独立 Face rig 现可从 `FaceFitSkeleton.HeadJoint` 或 `FaceDeformationSystem` 选父级，控制层放在 `FaceCustomSystem`；若同场景有 Body 角色登记，则同步扩展登记，否则由控制器自身的连接元数据维护身份。

原版 Cluster 路径先移动源 SoftMod 操作柄一个单位，读取变形前后顶点的 Y 坐标差，把实测位移写入 Cluster 权重；它不直接读取 SoftMod 的权重遮罩。`SoftModProbe` 和 `cluster_weights_from_probe()` 已编码这一换算，Maya 适配器已有临时隔离其他变形器、采样网格点、恢复源场景状态、创建 Cluster 并写入权重的路径。原版用最强权重顶点对应的网格边曲线驱动附着层；当前只记录该顶点，附着层仍由父关节约束驱动，贴面行为未复刻。

原版 Skin 路径建立新关节和 FK 方框控制，从源 SoftMod 半径／曲线配置 Maya Soft Selection，以软选择权重写入 SkinCluster 的新关节影响，再锁定新关节权重归一化。当前 Maya 适配器已有对应路径，限定网格恰好有一个可写 SkinCluster。原版另有指定 SkinCluster、新建分层 SkinCluster、50% Partial Parent 及自动镜像选项；这些分支尚未实现。CUSTOM-04 已接入 Maya Cluster 权重绘制工具；CUSTOM-05 已按原版用 X 轴反射顶点位置、最近顶点映射左右 Cluster 权重。CUSTOM-07 已编码控制器、变形器／关节和角色登记同步删除。三类转换及工具操作均未进行 Maya 验收；原版删除对侧控制器的行为尚未复刻。
