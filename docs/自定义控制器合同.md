# 自定义控制器内部合同

Body／Face 的 Custom Controllers 栏目按原版顺序展示：SoftMod Tool → Skin／Cluster／SoftMod 创建 → Cluster 权重绘制／镜像 → 添加影响对象 → 删除控制器。操作入口已接入代码，但所有 Maya 场景行为仍待集中验收。

AdvancedSkeleton 的 Skin、Cluster、SoftMod 自定义控制都从一个已绘制的 SoftMod 区域开始。SoftMod 是 Maya 的局部变形器：中心和顶点权重决定受影响的网格区域。[Skin Control](https://animationstudios.com.au/help/asSkinControlCreate.html)以新关节驱动该区域；[Cluster Control](https://animationstudios.com.au/help/asClusterControlCreate.html)使用 Cluster 变形器；[SoftMod Control](https://animationstudios.com.au/help/asSoftModControlCreate.html)保留 SoftMod 并增加可滑动的底座控制。官方说明中的默认父级是距离 SoftMod 中心最近的 DeformJoint；显式父级须属于 `DeformationSystem`。

内部输入 `SoftModRegion` 保存源操作柄、变形器、网格、中心、衰减半径／模式／曲线，以及顶点总数和完整权重遮罩。权重遮罩是 SoftMod 节点存储的逐顶点系数，不等于半径与曲线共同产生的最终位移。例如一个三顶点局部网格可记录为：

```python
SoftModRegion(
    deformer="BodyBicepSoftMod",
    mesh="|Character|BodyMesh",
    center=(12.3, 115.0, 2.4),
    vertex_count=3,
    weights=(WeightedVertex(0, 0.0), WeightedVertex(1, 0.75),
             WeightedVertex(2, 1.0)),
    source_handle="|BodyBicepSoftModHandle",
    falloff_radius=8.0,
    falloff_mode=0,
    falloff_curve=((1.0, 0.0, 3), (0.0, 1.0, 3)),
)
```

`plan_custom_controller()` 处理有限坐标、顶点范围、权重、原版名称及父关节选择。名称输入不含下划线，例如 `Bicep`；中心 X 为正生成 `Bicep_L`，否则生成 `Bicep_R`，选中 middle 时生成 `Bicep_M` 并将衰减中心的 X 设为零。局部朝向选项决定附着层是否先与父关节对齐。自动父级按世界空间平方距离比较，同距时按关节路径排序，以保证结果可重复。`BuildCustomController.plan()` 再通过宿主读取区域和 DeformationSystem 关节、检查节点名称和场景前置条件；`apply()` 在单个事务中写入并读回。

构建姿态位置由 `SurfaceAnchor` 保存为网格三角形的三个顶点编号及重心权重。例如顶点 `(12, 13, 27)` 的权重 `(0.2, 0.3, 0.5)`，在当前姿态和绑定姿态分别对同一编号的顶点求加权和，就能把同一个表面位置映射到两种姿态。Maya 宿主在转换事务中暂存已登记控制通道，切到默认平移／旋转／缩放，解析绑定姿态位置后建立控制器，最后恢复通道及动画连接；Face 独立 rig 使用 `FaceControlSet`。这取代了原版临时 UV 投射网格的定位手段，但当前并未覆盖原版 `buildPose` 保存的所有自定义属性，贴附位置和场景恢复均待 Maya 验收。

`ExtendSoftModController` 对应 [Add influenced object](https://animationstudios.com.au/help/asSoftModControlAddInfluencedObject.html)：输入已有自定义控制器和一件新增网格，先核对控制类型、影响集合与网格可写性。SoftMod／Cluster 将网格加入变形器，Skin 将控制关节加入目标网格的 SkinCluster，必要时新建 SkinCluster。写后以集合比较成员，不依赖 Maya 返回顺序；重复添加须在写入前拒绝。

原版 `asConvertSoftModToCustomControl` 的 SoftMod 分支是转换：从源节点读取衰减设置，创建新的 SoftMod、控制球和可移动底座；底座定位器驱动衰减中心，控制球通过矩阵节点驱动变形，结束时删除源操作柄。当前 CUSTOM-03 的 Maya 适配器按这个节点关系创建新变形器，并把完整遮罩写入新节点。CUSTOM-06 对 SoftMod／Cluster 使用 `geometry` 编辑命令；对 Skin Control 则将控制关节加入目标网格的 SkinCluster，目标网格没有 SkinCluster 时新建一个。两项均已接入 Body／Face 栏目，但没有运行真实 Maya。构建姿态重定位和右侧源自动镜像左侧已有代码，控制外观及局部父级仍有差距。独立 Face rig 现可从 `FaceFitSkeleton.HeadJoint` 或 `FaceDeformationSystem` 选父级，控制层放在 `FaceCustomSystem`；若同场景有 Body 角色登记，则同步扩展登记，否则由控制器自身的连接元数据维护身份。

原版 Cluster 路径先移动源 SoftMod 操作柄一个单位，读取变形前后顶点的 Y 坐标差，把实测位移写入 Cluster 权重；它不直接读取 SoftMod 的权重遮罩。`SoftModProbe` 和 `cluster_weights_from_probe()` 已编码这一换算，Maya 适配器已有临时隔离其他变形器、采样网格点、恢复源场景状态、创建 Cluster 并写入权重的路径。控制层位于不继承上级变换的 `ClusterControlGrp` 下；父关节的世界矩阵只驱动 `Attach` 朝向和缩放。最强权重顶点的一条网格边生成带历史的曲线，其端点通过 `pointOnCurveInfo` 驱动 `Attach` 平移；`MMT/DMT` 与 `MMR/DMR` 分别驱动 Cluster 操作柄的平移／缩放和旋转，`Subtract` 层抵消控制器自身平移。这些节点关系已编码，尚未进入 Maya 验收。

原版 Skin 路径建立新关节和 FK 方框控制，从源 SoftMod 半径／曲线配置 Maya Soft Selection，以软选择权重写入 SkinCluster 的新关节影响，再锁定新关节权重归一化。当前 Maya 适配器已有对应路径；目标蒙皮层留空时要求目标网格恰好有一个 SkinCluster，也可指定该网格已有的某一层，或选择新建分层 SkinCluster。分层路径创建或复用 `ExtraSkinClustersBaseJoint_M`，将新层排在原蒙皮层下游，把控制关节移入 `JointOffset` 并通过 `JointMM` 与 `offsetParentMatrix` 驱动。50% Parent 选项可为有父、子关节且名称不含 `Part` 的 Body 关节创建或复用同级 Partial 关节：位置和缩放跟随原关节，朝向在父级基准与原关节之间按 `follow` 参数混合，Skin Control 的新关节挂在该 Partial 关节下。三类控制器的右侧源自动镜像左侧按原版使用临时 SoftMod：以原姿态中心的 X 反射位置选择同网格或最近另一件网格，复制衰减参数，选择对侧父关节，再走相同转换路径；中间控制和左侧源不触发此分支。新建分层 SkinCluster 时，同网格左右侧共用新层；独立左右网格各创建对应层。显式指定现有 SkinCluster 的跨网格组合仍要求该层已经影响目标网格。三类控制器创建时向已有 `buildPose`／`faceBuildPose.udExtraAttr` 追加控制通道归零、可读的数值型自定义属性复位及底座归零命令；完整命令存于控制器自身，以便删除时精确移除。控制器同时加入 `ControlSet`／`FaceControlSet`。CUSTOM-04 已接入 Maya Cluster 权重绘制工具；CUSTOM-05 已按原版用 X 轴反射顶点位置、最近顶点映射左右 Cluster 权重。CUSTOM-07 已编码控制器、变形器／关节和角色登记同步删除；存在同类型 `_L`／`_R` 对侧控制器时先预检两侧，再在一次事务中一并删除。三类转换及工具操作均未进行 Maya 验收。
