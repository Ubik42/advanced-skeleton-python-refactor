# 来源骨架构建合同

## 输入数据

场景适配器将已摆成绑定姿态的关节树读成 `SourceSkeletonJoint` 序列。路径是场景中的完整关节路径；`parent` 是同一序列内的完整路径，根关节为 `None`；坐标为世界空间厘米值。序列顺序没有语义。

```python
SourceSkeletonJoint(
    path="|source:Root|source:Spine1|source:Chest",
    name="source:Chest",
    parent="|source:Root|source:Spine1",
    world_position=(0.0, 104.2, 0.8),
)
```

当前映射接受中心与右侧的标准身体关节；左侧由 Body 镜像生成。`Root`／`Pelvis`／`Hips` 映射至 Fit Root，Root 到 Neck 的脊柱链决定实际段数。五指输入必须完整。缺失的 `HeadEnd`、脚跟、脚尖末端和脚侧定位器由已有关节坐标推算。名称映射不是通用骨骼识别：非标准命名需在来源端整理，或另写一个显式映射器。

## 内部阶段

1. `capture_source_skeleton(root)` 只读来源树；`scene_up_axis()` 读取 Y／Z 向上设置。
2. `plan_source_skeleton_fit(joints, axis)` 校验唯一根、连通父链、名称、有限坐标和必需关节，输出 `SourceSkeletonFitPlan`。这一阶段不写场景。
3. `BuildFitFromSourceSkeleton.apply_plan()` 在目标角色内创建、定向 Fit；原来源关节保持不变。
4. `BuildCharacterFromFit.plan()` 从新 Fit 快照推断脊柱描述。随后构建 Body、控制器、角色登记；有网格时复制来源网格并逐件绑定 Skin。
5. `BuildCharacterFromSourceSkeleton.apply()` 将第 3～4 步纳入一个宿主事务。任一步抛错时，宿主撤销本次写入。

`SourceSkeletonFitHost` 和 `CharacterFromFitHost` 是场景能力接口：应用代码只调用捕获、创建、预检、读回和事务方法，不引用 Maya API。Maya 实现位于 `adapters`；无 Maya 环境可用实现同样方法的内存宿主推演计划。`CharacterFromFitResult` 分别记录 Body 构建结果和每件网格的 Skin 构建结果。

## 当前边界

来源树、Fit、Body、Skin 的内部编排已实现。公开 Sam 五指来源的后台完整构建结果属于这次应用层重排之前的基线；重排后的图形窗口操作、保存重开和 FBX 整链尚未统一验收。权重是新建的 Closest Distance 权重，不等于原版角色权重迁移。
