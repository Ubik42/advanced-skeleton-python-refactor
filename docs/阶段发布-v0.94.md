# v0.94 Maya-first 阶段展示版

v0.94 是当前 Maya Python 重构阶段的暂停点。它把授权安装中的行为研究结果整理为独立的 Python core、application 用例与 Maya adapter，不提交 ADV 原始 MEL、模板、图标、场景或由原代码逐行派生的实现。

## 可演示的黄金路径

1. 用合成模板创建 FitSkeleton，并生成带 provenance 的 30 关节或 70 关节五指 Body。
2. 在一次 Maya Undo 事务中构建 Arm、Leg、Hand 与 Global 控制结构，并从真实场景重新读取关键节点和连接。
3. 生成 Root Motion 和完整 Export Skeleton，在明确帧范围内 bake 后发布带显式版本、单位、Up Axis 与编码 Profile 的 FBX。
4. 检查显式 MoCap 来源与关节映射，以 maintain-offset 临时约束驱动 owned Body，再安全断开或 Undo。

## 工程结构

- `adv_py.core`：DCC 无关的数据、计划、数学与审计规则。
- `adv_py.application`：场景捕获、预检、事务编排与结果复检。
- `adv_py.adapters`：Maya 场景实现；Blender adapter 在第二阶段前冻结。
- `tests`：不依赖 DCC 的快速回归测试。
- `validation`：自行生成测试场景并由 Maya 2024 standalone 执行的宿主验证。

## 已验证范围

- Windows；Python 3.10/3.14。
- Maya 2024 standalone。
- 272 项纯 Python 测试。
- 30 关节基础 Body、70 关节五指 Body、31 关节独立导出层级。
- MoCap 临时驱动验证包含姿态保持、跨帧响应、断开、两级 Undo、选择与时间保持。

运行纯 Python 回归：

```powershell
$env:PYTHONPATH = "src"
py -3 -m unittest discover -s tests
```

运行当前 MoCap 宿主验证：

```powershell
& 'C:\Program Files\Autodesk\Maya2024\bin\mayapy.exe' `
  validation\maya_mocap_connection_smoke.py `
  validation\results\maya2024-mocap-connection.json
```

## 当前边界

- 暂不继续新增 Maya 功能；下一候选里程碑是显式 MoCap 采样与 bake。
- Blender 第二阶段尚未启动，不把早期 adapter 可行性代码描述为完整迁移。
- 不包含产品 UI、厂商自动映射表、外部 FBX 自动导入、动画曲线简化或引擎专用骨名表。
- 本工程是私有研究与迁移项目，使用者仍需自行确认 AdvancedSkeleton 和 Autodesk Maya 的许可条件。
