# 开发交接

本文件记录 `v0.95.0` 后的接手边界。事实基线以提交 `ddd4ec1` 和 [阶段说明](阶段发布-v0.95.md) 为准；后续功能完成时，应更新版本记录，不能把计划写成已实现能力。

## 当前状态

- 主线是 **先完成 Maya Python 重构，再迁移 Blender**。Blender 5.2 的现有适配器只证明部分核心合同可跨宿主运行，不代表第二阶段已经开始。
- Maya 侧已有 90 个纵向切片，覆盖 Fit、Body、Arm / Leg / Hand FK/IK、Skin、Root Motion、FBX 和 MoCap 临时驱动。基线包含 272 项纯 Python 回归测试与 79 个宿主 smoke 脚本；这些是 `v0.95.0` 的记录，不是未来提交的自动结论。
- 最近完成的 MoCap 纵切支持显式 Body 映射、临时约束、断开和 Undo。**下一个候选纵切是显式采样与 bake**：由调用者指定来源、目标、帧范围与采样步长；先形成可预检的计划，再把逐帧结果写成 Maya 动画曲线，复检关键帧和场景状态。实现前应核对现有接口，不能推断自动映射、外部 FBX 导入或曲线简化已经存在。
- 产品 UI、复杂外部角色自动适配和 Blender 正式功能迁移均不在当前基线内。

## 实施边界

1. `src/adv_py/core/` 保持 DCC 无关，表达数据、计划与校验；`application/` 编排用例；`adapters/maya/` 执行 Maya 场景操作。不要把 `maya.cmds` 或 `bpy` 引入核心。
2. 写入前检查对象归属、名称、类型、锁定与外部连接；在单一 Maya Undo 事务中提交；提交后从场景读回验证。失败不能留下半成品。测试用自行生成的场景和骨架。
3. 不提交 AdvancedSkeleton 原始 MEL、模板、图标、场景、文档或逐行派生代码。授权安装只作为本机行为参考；仓库保持私有，包元数据当前为 `Proprietary internal tooling`。
4. 不修改、构建、提交或推送 `D:\work\_tools\resume-shen-yuyan-editable`。作品展示如需同步，只处理另行授权的个人主页仓库 `D:\work\_tools\Ubik42.github.io`；普通功能开发不自动改主页。
5. 不启动 Maya 或 Blender 图形界面，也不频繁弹窗口。优先用纯 Python 测试和后台宿主 smoke；只运行与改动相关的验证，避免每次全量宿主测试。
