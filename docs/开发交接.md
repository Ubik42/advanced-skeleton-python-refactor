本文件记录 `v0.96.0` 后的接手边界。已验证能力见 [阶段说明](阶段发布-v0.96.md)，候选计划不代表已实现能力。

## 当前状态

- 开发顺序保持 **Maya-first、Blender-second**；Blender 只保留早期合同可行性验证。
- Maya 侧已有 91 个纵向切片。本轮纯 Python 全量回归 278 项通过；仓库包含 80 个宿主 smoke 脚本，本轮只重跑 MoCap bake 与相邻连接 smoke。
- 最新切片 `BakeMocapBody` 消费已连接的显式映射，保留建立连接时的 offset；显式整数帧范围和步长必须落在来源 clip 内且包含结束帧。先采样，再在单一 Undo 事务中移除临时驱动、写入 linear keys，复检直接曲线、局部值与世界矩阵。
- Maya 2024 自生成场景验证：10 个采样点、18 条曲线、180 个关键帧；锁定和外部消费拒绝、失败回滚、Undo / Redo、选择与时间保持、删除来源后回放全部通过。
- 下一候选是 MoCap 显式映射的路径无关保存 / 加载，或 bake 对动画层与更复杂输入的预检覆盖。先核对实际调用需求和证据；当前不支持动画层、引用目标、历史依赖约束、曲线简化、自动映射、外部 FBX 导入或 Control Rig 重定向。

## 实施边界

1. `src/adv_py/core/` 保持 DCC 无关，表达数据、计划与校验；`application/` 编排用例；`adapters/maya/` 执行 Maya 场景操作。不要把 `maya.cmds` 或 `bpy` 引入核心。
2. 写入前检查对象归属、名称、类型、锁定与外部连接；在单一 Maya Undo 事务中提交；提交后从场景读回验证。失败不能留下半成品。测试用自行生成的场景和骨架。
3. 不提交 AdvancedSkeleton 原始 MEL、模板、图标、场景、文档或逐行派生代码。授权安装只作为本机行为参考；仓库保持私有，包元数据当前为 `Proprietary internal tooling`。
4. 不修改、构建、提交或推送 `D:\work\_tools\resume-shen-yuyan-editable`。作品展示如需同步，只处理另行授权的个人主页仓库 `D:\work\_tools\Ubik42.github.io`；普通功能开发不自动改主页。
5. 不启动 Maya 或 Blender 图形界面，也不频繁弹窗口。优先用纯 Python 测试和后台宿主 smoke；只运行与改动相关的验证，避免每次全量宿主测试。
