## 实施边界

1. `src/adv_py/core/` 保持 DCC 无关，表达数据、计划与校验；`application/` 编排用例；`adapters/maya/` 执行 Maya 场景操作。不要把 `maya.cmds` 或 `bpy` 引入核心。
2. 写入前检查对象归属、名称、类型、锁定与外部连接；在单一 Maya Undo 事务中提交；提交后从场景读回验证。失败不能留下半成品。测试用自行生成的场景和骨架。
3. 不提交 AdvancedSkeleton 原始 MEL、模板、图标、场景、文档或逐行派生代码。授权安装只作为本机行为参考；仓库保持私有，包元数据当前为 `Proprietary internal tooling`。
4. 不修改、构建、提交或推送 `D:\work\_tools\resume-shen-yuyan-editable`。作品展示如需同步，只处理另行授权的个人主页仓库 `D:\work\_tools\Ubik42.github.io`；普通功能开发不自动改主页。
5. 不启动 Maya 或 Blender 图形界面。先完成一组连贯的核心代码与架构改造，再集中运行相关纯 Python 回归和后台角色 smoke；测试失败再针对修复复验。代码内的场景预检、事务回滚与读回属于运行时合同，继续保留。
