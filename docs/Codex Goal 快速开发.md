每轮从主链的最高优先级缺口开始：标准 Fit／骨架 → 完整 Body 与控制器 → Skin → 保存重开 → 导出。优先消除阻断主链的通用 Fit Part、Twist、Inbetween 和控制器分支；主链收齐后继续完成覆盖矩阵中的原版公开功能。选择一条能接入当前主构建或现有面板的操作链，先核对对应 MEL 过程的输入、条件、命名、层级、连接、控制属性和异常路径，再连续写完 Core 规则、Application 编排、Maya 宿主、入口、必要的登记与状态回读。已有模块优先复用；孤立计划、空按钮和仅适用于迁移角色的实现不算完成。

代码阶段以整条链为单位连续开发。写完后只运行一次必要的语法／导入和差异检查；发现错误时修复受影响范围，不逐函数启动 Maya，不为已知未验的其他模块重复测试。关键主链代码收齐后，集中执行一次真实 Maya 整链验收：从标准 Fit 创建角色，检查控制、变形、Skin、撤销、保存重开与导出；对失败点定向修复和复验。静态检查通过只能记为“代码已接入”，不能记为“Maya 已验收”。

原版行为不清时先查 MEL 调用和本地原版资产；只实现有依据的行为。确需原版模板但本地缺失时，记录准确阻塞项，转做另一条独立链路。不得自造替代资产冒充原版，也不得把未运行的 Maya 链路称为完成。保护已能使用的功能、旧角色路径、左右侧、命名空间以及 Y／Z Up；对某一分支的变更必须核对这些适用条件。

每轮至少交付一条接到主流程的实质代码链路。简短更新覆盖矩阵：已接入的行为、未实现分支、是否经过 Maya 验收、下一处最高优先级缺口。允许本地提交保存成果；**不要推送 GitHub、创建 PR、部署或更新个人主页**，除非用户明确改口。标准 Fit 经可见面板稳定完成完整角色、控制、变形、保存重开及导出，且覆盖矩阵内原版公开操作均已实现或逐项明确排除并经过相应 Maya 验收后，才将 Goal 标记为完成。
