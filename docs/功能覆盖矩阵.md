## 状态定义

| 状态 | 含义 |
| --- | --- |
| 未实现 | 界面只有栏目占位，没有对应 Python 操作 |
| 入口已接入，行为覆盖待审计 | 至少一个操作可以进入现有 Python 用例；尚未证明与原版栏目完整等价 |
| 行为已实现 | 公开操作、参数、结果和失败条件均已映射到 Python 实现 |
| Maya 已验收 | 在真实可见 Maya 会话中完成操作，并验证撤销／重做与保存重开 |
| 生产基线通过 | 公开示例资产和多套差异资产通过完整工作流 |
| 明确排除 | 经记录后决定不复刻，并说明替代方案或排除原因 |

## 下一轮拆分顺序

1. UI-04 Body / Fit：列出 Fit 创建、编辑、镜像、方向、元数据和导入导出行为。
2. UI-06 Body / Build：列出 Build、ReBuild、构建选项、所有权和保留数据行为。
3. UI-39、UI-41 Pose：列出驱动系统、姿态、动画、模式切换和空间切换行为。
4. UI-42、UI-47 Tools / Export：列出 MoCap 输入、映射、烘焙、导出骨架和 FBX 发布行为。
