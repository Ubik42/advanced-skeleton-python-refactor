## 状态定义

| 状态 | 含义 |
| --- | --- |
| 未实现 | 界面只有栏目占位，没有对应 Python 操作 |
| 入口已接入，行为覆盖待审计 | 至少一个操作可以进入现有 Python 用例；尚未证明与原版栏目完整等价 |
| 行为已实现 | 公开操作、参数、结果和失败条件均已映射到 Python 实现 |
| Maya 已验收 | 在真实可见 Maya 会话中完成操作，并验证撤销／重做与保存重开 |
| 生产基线通过 | 公开示例资产和多套差异资产通过完整工作流 |
| 明确排除 | 经记录后决定不复刻，并说明替代方案或排除原因 |

## Body / Fit、Edit、Build 操作层

| 操作编号 | 操作 | 主要输入 | 写入与结果 | 失败边界 | 当前证据 |
| --- | --- | --- | --- | --- | --- |
| FIT-01 | 导出当前 Fit | 命名空间、容器、目标 JSON | 只读捕获层级、设置、元数据和变换，原子写入文档 | 容器无效、层级或设置不完整、目标文档不可写时拒绝 | 纯 Python、Maya 后台、产品控制层 |
| FIT-02 | 从文档导入 | Fit JSON、目标命名空间和容器 | 在空场景创建容器和关节，写后读回 | 文档摘要、层级、名称、设置或已有目标冲突时拒绝 | 纯 Python、Maya 后台、产品控制层 |
| EDIT-01 | 更新 Fit 位置 | 每行一个关节和本地 XYZ | 单事务修改可写平移轴，保持层级和容器设置 | 重复目标、非有限数值、锁定轴、Root 偏离中心时预检拒绝 | Maya 2024 产品控制层写入与单次 Undo |
| EDIT-02 | 更新 Fit 元数据 | 目标关节、字段、类型化值或删除 | 单事务增删 AdvancedSkeleton 语义字段，写后逐项读回 | 字段类型、枚举、依赖关系或范围无效时预检拒绝 | Maya 2024 产品控制层写入与单次 Undo |
| EDIT-03 | 按子级重新定向 | 单子级链中的目标关节 | 重建 jointOrient，同时保持后代世界位置和元数据 | 分支关节未指定子级、锁定朝向轴、World Orient 策略冲突时拒绝 | Maya 2024 产品控制层写入与单次 Undo；界面尚未提供分支子级选择 |
| BUILD-01 | 构建并登记角色 | Fit 容器、脊柱段数、头部瞄准选项 | 构建 Body、控制器和角色登记 | Fit 不完整、命名冲突、外部连接或构建复检失败时整体回滚 | 30／70／可变脊柱后台场景；面板控制层 |
| BUILD-02 | 重建并保留数据 | 已登记角色、暂存命名空间、附件根 | 单事务重建并接回已声明数据 | 未登记角色、名称占用、未知外部依赖或所有权不明时拒绝 | 自生成角色后台重建、Undo／Redo、保存重开 |
| BUILD-03 | 替换脊柱角色并保留数据 | 来源／目标角色、Skin、网格、动画范围和保留根 | 接管原命名空间，迁移动画、Skin、附件和数据图 | 映射歧义、引用未加载、误差超限或外部依赖未声明时回滚 | 自生成多 Skin、Face、附件与引用组合后台验收 |

## 下一轮拆分顺序

1. 扩展 EDIT-03：为分支关节增加显式子级选择，并接入 World Orient 策略。
2. UI-39、UI-41 Pose：列出驱动系统、姿态、动画、模式切换和空间切换行为。
3. UI-42、UI-47 Tools / Export：列出 MoCap 输入、映射、烘焙、导出骨架和 FBX 发布行为。
4. UI-18、UI-21、UI-22：盘点自定义控制器、控制曲线与控制朝向的已有底层能力。
