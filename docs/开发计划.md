# 开发计划与当前缺口

更新日期：2026-09-29。目标是以 Python 复刻 AdvancedSkeleton 6.925 的 Maya 行为与界面入口；内部结构允许重组，功能和结果须逐项对照原版。原 MEL 位于本机只读参考目录，不纳入本仓库。

## 开发轮次硬性门禁

每轮至少进行 30 分钟实际开发，只有整个复刻开发真正完成才能提前结束。开轮记录 UTC 开始时间，结束前再读取并核算；未满 1800 秒继续开发核心代码。不能把写计划、查阅、汇报、等待或静态检查冒充连续开发，也不能用人为拆分的“本轮切片”作为提前结束理由。一次提交、一个局部功能、一条小链路完成或某个分支遇阻，均须接着开发其他核心功能，不能当作收工点。30 分钟只是最低时长，不是停止开发的目标。当前先连续补全内部 Python 逻辑，集中做必要的静态检查；真实 Maya 整链测试放到核心代码齐备之后。详见[Codex Goal 提示词](CODEX_GOAL_快速开发.md)。

## 当前结论

**尚未完成全量复刻。** 标准 Fit 到 Body、控制器、新 Skin、动画和 FBX 有过 Maya 运行基线；当前 HEAD 在这些验收之后又改动了 Fit Part、Inbetween、控制器层级、选择集和重建等主链，因此历史通过不能证明当前版本可用。原版公开操作清单仍不完整，不给出整体完成百分比。详见[功能覆盖矩阵](功能覆盖矩阵.md)和[历史验收记录](历史验收记录-v0.96.md)。

本轮继续沿主构建补代码：原版脚部 Heel／BigToe／PinkyToe 临时 Body 标记在 Foot 控制定位之后、角色登记和 Skin 之前删除，并同步骨架归属计数；已有旧角色的重建保留其原有标记拓扑。FBX rig 构建也移除这些临时关节和对应的空壳 FK 控制器，从来源动画转接及 FK 曲线尺寸投影中排除对应的已删变形目标，并让 IK/FK 切换同步 FK 曲线可见性。面板在未找到 Fit 且只选中一个来源根关节时，现接通来源骨架→Fit→Body／控制→Skin 用例；该入口的脊柱段数和标签推断选项已传到底层，公开构建入口还补上原版厘米单位门禁。以上均为代码阶段，尚未经过真实 Maya 验收。

通用附加 Fit 分支已进入 Body 主构建、FK 层级、缩放与分段补偿、登记及重建策略；创建后回读控制层与约束。来源骨架中仅左侧存在的附加分支现可沿父链带入普通子关节，并按原版 `noMirror/noMirrorLeft` 规则定位到最终左侧 Body。当前仍属于代码接入，未经 Maya 验收，不能据此宣称任意附加骨架已经完成复刻。

“代码已接入”指 Core、应用层、Maya 宿主及入口之间存在调用路径；“Maya 已验收”须有当前实现的真实场景结果。独立计划、宿主接口、面板占位或旧版测试都不计为行为完成。

上述不是完整 MEL 过程清单。[功能覆盖矩阵](功能覆盖矩阵.md)现有操作登记仍需逐个和原版菜单、过程、默认参数及条件分支核对；不能把“有同名 Python 文件”当成原版功能覆盖。

主构建已把 Twist／Inbetween Part 的建立与 Body 改挂提前到 FK／IK 控制器之前，与原版 `asBuildAdvancedSkeleton` 的阶段顺序一致。控制器规划使用改挂后的真实 DAG 路径，同时将 Part 视作变形中间层，沿原 Body 语义父链规划控制；扭转投影在控制器建成后接线，矩阵参照留在 Part 之外的原父链。该重排尚未运行 Maya，不能认定 IK 求解、父子空间与重建已等价。CurveGuide、Wheel／RollingBall 的 Core、Maya 建图和登记已进入 Body 主构建，命名空间命令边界也补上了切线约束和表达式创建；这些组合仍未在当前 Maya 版本验收，不能记为完成等价复刻。

Body Fit／Advanced 切换已补上原版 `asDsToFitSkeleton` 的驱动曲线元数据迁移；Fit 非对称分支创建／移除、`_NonSymmetry` Body 命名及 Fit 文档往返已接入。Delete Adv 已按 AllSet 删除 Body 生成节点并保留 Fit、原有模型和 Fit 驱动曲线；本轮将 Face 生成节点登记到 FaceAllSet，接入 Face 删除对 Skin 影响、构建姿态及 Fit 的交接，并让 Delete Adv 在同一撤销事务内先删除 FaceSetup，再删除 Body。原版完整 FaceSetup 仍未重构完成，旧场景缺少 FaceAllSet 时该删除会拒绝以避免误删。上述新路径只完成代码接入，尚未运行 Maya。

## 下一阶段工作顺序

1. 冻结外围扩张。先以当前代码和 MEL 核对 P1 主构建、重建、发布三条真实调用链，列出阻断项，不再增加孤立计划模块。
2. 沿已经共用的 `BuildRegisteredBodyCharacter` 主链收齐原版分支；重建只保留旧数据捕获、通道兼容和交接，不再复制 Body／Rig 构建流程。
3. 核心链代码齐备后做一次集中 Maya 验收，覆盖公开 Sam、差异骨架、双 Skin、保存重开、重建、写键和 FBX。只修验收暴露的失败点，避免逐小函数频繁跑 Maya。
4. 再按覆盖矩阵完成 P2～P4。Blender 仍属第二阶段。
