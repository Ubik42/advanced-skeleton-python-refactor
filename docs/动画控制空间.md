# 动画控制空间

控制空间决定一个控制器跟随哪个父级运动。手部在 `body` 空间跟随胸部，在 `global` 空间跟随全局控制器；脚部的身体来源是根关节，头部的身体来源是颈关节。头部只切换旋转来源，位置仍由原有头颈层级决定。每只手脚的目标控制器与 Pole 控制器成组切换，避免只移动目标而改变弯曲平面。

## 入口和事件语义

已登记的 30 / 70 关节角色可显式启用空间动画。安装保留原控制器、用户曲线和约束输出路径；新增五个离散模式通道及 102 个偏移通道，共 107 个通道。已启用四肢长度、朝向及体积匹配的角色从 205 / 309 个通道扩展到 312 / 416 个。

```python
from adv_py.adapters import MayaBodyBuildHost
from adv_py.application import (
    EnableBodyCharacterSpaceAnimation, SwitchBodyCharacterSpace,
    CaptureBodyCharacterAnimation, ApplyBodyCharacterAnimation,
)

host = MayaBodyBuildHost()
EnableBodyCharacterSpaceAnimation(host).apply()

# 第 10 帧起右手跟随胸部；第 20 帧起恢复全局空间。
SwitchBodyCharacterSpace(host).execute("hand_R", "body", 10)
SwitchBodyCharacterSpace(host).execute("hand_R", "global", 20)

clip = CaptureBodyCharacterAnimation(host).execute(1, 21)
ApplyBodyCharacterAnimation(host).apply(clip)
```

空间标识为 `head`、`hand_R`、`hand_L`、`foot_R`、`foot_L`。事件时刻要求整数帧；当前时间和选择保持调用前状态。每次安装或切换占一笔 Undo；重复安装、切换到当帧已有来源均不重复写入。

切换保证事件帧的身体与控制空间目标世界矩阵连续，事件之前的曲线保留。事件之后，控制器开始跟随新的来源，运动轨迹会按新来源变化。在已有事件之间插入切换时，后续已记录的来源和偏移键保持不变。首次给某个来源写偏移键时，在事件前一帧记录旧值，避免 Maya 曲线的首键前延伸改变历史姿态；已有更早的阶梯键则直接保留。

旧 `SwitchBodyControlSpace` 是静态重绑定接口。启用动画空间后，应使用带明确帧号的 `SwitchBodyCharacterSpace`；旧接口不会删除新的双来源约束。

## 场景结构

每个空间目标有两枚 transform 偏移节点，分别位于身体来源和全局来源下面；约束同时连接两枚节点，只激活其中一个。头部使用 orientConstraint，手脚使用 parentConstraint。五个模式属性位于现有 Global 控制器，取值 `body=0`、`global=1`；reverse 节点提供互补权重。空间模式和偏移均采用阶梯出切线，不插值混合两个来源。

例如右手目标的语义通道包含：

```text
space.hand_R.mode = 0
space.hand_R.0.body.translateX = …
space.hand_R.0.body.translateY = …
space.hand_R.0.body.translateZ = …
space.hand_R.0.body.rotateX = …
space.hand_R.0.body.rotateY = …
space.hand_R.0.body.rotateZ = …
```

`0` 表示目标控制器的 offset；`1` 表示 Pole 的 offset。数值是对应来源下的局部偏移，来自当前世界姿态反解，不能当作世界坐标直接填入。偏移节点无额外缩放、剪切、旋转轴或父级矩阵修正。登记检查 UUID、父级、原生动画输入、约束来源、权重和消费端，拒绝外部共享、替换连接及未登记偏移。

## 动画文档

原版本 1 保持整段片段空间来源一致的合同。启用空间动画后，编码器输出版本 2，允许各帧来源变化，同时要求五组模式通道与姿态中的来源一致。版本 2 没有改变身体矩阵的用途：它们仍是求解结果参考，不作为骨骼写入数据。

片段恢复和全身写键按通道语义设置切线：空间状态及偏移用阶梯，其余控制值沿用线性 Euler。FK/IK 烘焙能够处理包含空间事件的采样序列。模式转换保证显式采样帧的姿态，不承诺稀疏采样点之间的任意曲线形状。恢复跨事件的动画应包含事件帧，通常逐帧采样。

## 验证与边界

后台入口为 `validation/maya_character_space_animation_smoke.py`。30 / 70 关节场景使用已有身体网格和辅助骨骼网格，覆盖五组空间切换、返回、插入事件、历史与未来事件保持、安装及切换 Undo / Redo、版本 2 文档往返和片段恢复。30 关节额外覆盖全局平移、旋转、1–1.2 倍缩放与躯干旋转，验证切换之后确实跟随新来源；安装与事件帧最大矩阵元素误差约 `5.33e-15`，网格位置差为 0。

70 关节独立进程重开后，姿态及网格与保存结果一致，并通过继续空间切换、四肢 FK 烘焙和脊柱 IK 烘焙。故障用例覆盖外部消费、非阶梯模式曲线、安装中途异常和事件写入中途异常；异常后登记、原曲线和实际姿态恢复。

当前要求 cm / degree、Undo 开启、正等比缩放、原生独占时间曲线、无动画层。完整角色的 namespace 与多角色隔离见[多角色与命名空间](多角色与命名空间.md)，引用角色拒绝写入；其余工作按[剩余开发清单](剩余开发清单.md)开发。
