# 脊柱影响重分配

跨拓扑 Skin 转移先将源网格权重投影到目标表面。源、目标角色的脊柱段数不同时，还需将每个源关节的权重分给目标关节：原有 `--mapping` 只支持一对一，`--redistribution` 支持明确的一对多比例。两者不能同时提供。

例如源链为 Root、Spine1、Spine2、Chest，目标链为 Root、Spine1–Spine4、Chest。按两条链各自从 0 到 1 的位置，源 Spine1 落在目标 Spine1 与 Spine2 之间，分别得到该源权重的 `1/3` 和 `2/3`；源 Spine2 落在目标 Spine3 与 Spine4 之间，分别得到 `2/3` 和 `1/3`。一个原顶点若有源 Spine1 权重 `0.5`、Arm 权重 `0.5`，重分配后目标 Spine1、Spine2、Arm 分别为 `1/6`、`1/3`、`1/2`。

以下是完整的输入结构；所有参与源 skinCluster 的影响关节均须列出，`target_influences` 也须包含目标 skinCluster 的完整关节集合。实际路径以 Maya 中的完整 DAG 路径为准。

```json
{
  "target_skin": "TargetSkin",
  "target_mesh": "|TargetMesh",
  "target_influences": [
    "|DstRoot",
    "|DstRoot|DstSpine1",
    "|DstRoot|DstSpine1|DstSpine2",
    "|DstRoot|DstSpine1|DstSpine2|DstSpine3",
    "|DstRoot|DstSpine1|DstSpine2|DstSpine3|DstSpine4",
    "|DstRoot|DstSpine1|DstSpine2|DstSpine3|DstSpine4|DstChest",
    "|DstArm"
  ],
  "influences": [
    {"source": "|SrcRoot", "targets": [{"path": "|DstRoot", "fraction": 1.0}]},
    {"source": "|SrcRoot|SrcSpine1", "targets": [
      {"path": "|DstRoot|DstSpine1", "fraction": 0.3333333333333333},
      {"path": "|DstRoot|DstSpine1|DstSpine2", "fraction": 0.6666666666666666}
    ]},
    {"source": "|SrcRoot|SrcSpine1|SrcSpine2", "targets": [
      {"path": "|DstRoot|DstSpine1|DstSpine2|DstSpine3", "fraction": 0.6666666666666666},
      {"path": "|DstRoot|DstSpine1|DstSpine2|DstSpine3|DstSpine4", "fraction": 0.3333333333333333}
    ]},
    {"source": "|SrcRoot|SrcSpine1|SrcSpine2|SrcChest", "targets": [
      {"path": "|DstRoot|DstSpine1|DstSpine2|DstSpine3|DstSpine4|DstChest", "fraction": 1.0}
    ]},
    {"source": "|SrcArm", "targets": [{"path": "|DstArm", "fraction": 1.0}]}
  ]
}
```

源资产由 `skin-surface-source-export` 在原场景生成，目标场景须已有目标网格、全部目标关节及 skinCluster。后台入口为：

```text
adv-rig skin-surface-transfer target_before.ma --namespace : \
  --source-asset source_asset.json --target-skin TargetSkin \
  --target-mesh '|TargetMesh' --redistribution redistribution.json \
  --max-distance 0.000001 --output target_after.ma
```

Maya 角色工作台的“蒙皮 → 跨拓扑权重转移”页也可把“关节转换方式”设为“一对多影响重分配”，并选择同一份文档。控制层与后台命令调用相同的 application 用例。

每个源关节的分配比例须为有限正数且和为 1；源集合不全、目标路径不存在或比例有损时拒绝。顶点权重经同名目标关节累加，再按目标 skinCluster 的最大影响数和允许裁剪损失进行预检。Python 入口 `linear_spine_weight_redistribution` 可按均匀段位生成上述比例；弯曲或不等距脊柱可显式提供两条链从 Root 到 Chest 严格递增的归一化弧长位置。

自生成独立源／目标 Maya 场景已验证 4→6 段影响迁移与 4→9 顶点表面转移叠加：目标角点的 Arm、Spine1、Spine2 权重为 `1/2`、`1/6`、`1/3`，重开后目标网格由这些权重实际变形；目标权重单次撤销／重做恢复，比例有损时无输出场景且输入场景不变。

这项操作迁移的是 Skin 权重数据，要求目标骨架与 skinCluster 预先建立；它不重建角色、不重定向控制动画，也不迁移绑定矩阵或其他变形器。现有完整角色原位重建仍只接受同布局。

同场景的两个已登记可变脊柱角色也可直接由绑定矩阵生成比例。`registered_spine_weight_redistribution` 读取两份角色登记中的 Root→Chest 绑定位置，按实际弧长定位目标影响；脊柱外影响关节按同名 Body 关节对应。来源 Skin 可只使用部分脊柱关节，目标 Skin 须包含完整目标脊柱影响链。未映射的目标影响默认拒绝；显式允许时，这些影响在目标顶点会清零。后台命令无需手写比例文档：

```text
adv-rig skin-surface-transfer two-characters.ma --namespace target \
  --registered-source-namespace source \
  --source-skin source:SourceSkin --source-mesh '|source:SourceMesh' \
  --target-skin target:TargetSkin --target-mesh '|target:TargetMesh' \
  --max-distance 0.000001 --output transferred.ma
```

自生成四段→六段双角色场景中，来源顶点的 Spine1 `0.5` 按绑定弧长分成目标 Spine1 `0.25`、Spine2 `0.25`，肩部 `0.5` 保留。目标四个顶点完成权重写入，来源权重不变，目标网格在已迁移 FK 动画的第 1→10 帧发生实际形变；单次撤销／重做和后台命令写出后的新进程重开均通过。

需要将 FK 控制动画和目标 Skin 权重作为同一次编辑时，使用 `MigrateRegisteredSpineCharacter` 或后台命令 `character-spine-migrate`。它先预检两份角色登记、源／目标 Skin、几何对应和绑定段位，再在一个 Maya Undo 事务内写入权重与目标控制曲线；控制写入中途失败会恢复两者。以下命令的输入场景须已包含两个登记角色、源／目标网格及 skinCluster：

```text
adv-rig character-spine-migrate two-characters.ma --namespace target \
  --source-namespace source --source-skin source:SourceSkin \
  --source-mesh '|source:SourceMesh' --target-skin target:TargetSkin \
  --target-mesh '|target:TargetMesh' --start 1 --end 10 \
  --max-distance 0.000001 --output migrated.ma
```

四段→六段、10 帧、7 组 FK 控制与 4 个顶点的自生成场景已通过：故障注入恢复旧控制键和旧目标 Skin，成功写入一次撤销／重做同时恢复动画与权重；产品命令输出在新 Maya 进程重开后仍保留目标 FK 键和分段权重。目标 Rig、目标网格及其绑定矩阵仍须预先建立；这是一项跨角色迁移，尚未在原角色位置替换旧 Rig，也不迁移其他变形器或用户附件。

若需要保留**原网格与原 skinCluster 节点**，`HandoffRegisteredSpineSkinCluster` 在两个角色均处于登记绑定姿态时，将目标完整脊柱链和同名非脊柱影响加入原 skinCluster，按绑定弧长写入全部顶点权重，再移除旧影响，并从该 skinCluster 独占的 bindPose 中移除旧骨架成员。整个过程为单次 Undo 事务；新增影响时旧权重必须保持原值，目标影响的绑定逆矩阵须与目标角色登记一致，结束时核对权重、网格中性位置、网格和 skinCluster UUID、变形历史。后台命令：

```text
adv-rig spine-skin-handoff two-characters.ma --namespace source \
  --replacement-namespace target --skin source:SourceSkin \
  --mesh '|source:SourceMesh' --output handed-off.ma
```

自生成 Maya 2024 四段→六段场景中，原网格的 `source:SourceSkin` 保持同一节点，目标 Spine1／Spine2 各获得 `0.25`、肩部保留 `0.5`；目标已迁移控制动画可驱动该原网格。原 skinCluster 的 bindPose 不再连接旧骨架，Skin 后的 DeltaMush 仍在相同变形历史中。中途故障整体回滚、单次撤销／重做及产品命令输出的新进程重开均通过。此操作尚未删除旧 Rig、提升新 Rig 到原角色命名空间，未处理其他 Skin 或所有生产变形器组合；不能据此认定原位变拓扑角色重建完成。
