# 兼容与旧实现依赖清点

当前运行分层由 `core`、`application`、`adapters` 和 `product` 组成。静态边界检查遍历 `src/adv_py` 中除 `legacy` 目录外的 196 个 Python 模块及 1513 条导入：运行层没有引用 `LegacyMelBridge` 或导入 `adv_py.legacy`；`core`、`application` 与 `product` 没有直接导入 `maya`／`bpy`。Maya 适配层仍有 22 处 MEL 调用，集中在 `maya_body.py` 的 Autodesk FBX 插件参数与导出命令，并非 AdvancedSkeleton 过程调用。

`src/adv_py/legacy/bridge.py` 保留为显式兼容工具；当前产品入口、应用用例和 Maya 运行适配层没有调用它。`adv_migration` 的 MEL 清单命令只读本机授权源码，用于分析，不参与角色构建或动画运行。检查命令：

```powershell
python validation\architecture_boundary_audit.py validation\results\architecture-boundary.json
```

这项检查证明运行代码没有回退到旧 MEL 桥接，不证明原工具的全部行为已被覆盖。剩余的行为缺口按 [剩余开发清单](剩余开发清单.md) 的工作包管理，主要包括不同拓扑的角色重建、广泛生产资产兼容性、自动面部解剖标记与外部目标资产管理、复杂外部动画曲线、产品交互界面及 Blender 正式迁移。现有同布局角色重建可通过后台产品入口执行，并在自生成 30 关节动画角色上验证完整动画保持。
