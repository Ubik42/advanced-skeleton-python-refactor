# v0.96.0 阶段发布

本版继续 Maya-first 的 Python 重构。它是可验证的开发阶段版本，不表示已经替代 AdvancedSkeleton 的全部绑定能力。原始 MEL、模板、图标、场景和文档不随仓库分发；仓库保持私有。

## 已完成范围

- 分层工程：DCC 无关的 Core 保存数据合同、计划和校验；Application 组织预检、场景提交和结果复检；Maya Adapter 执行 DAG、DG、动画与文件操作。
- 角色主链：Fit 创建及 JSON 往返、30/70 关节 Body、躯干与四肢 FK/IK、手部控制、显式蒙皮权重和角色登记。
- 动画与交付：姿态及动画文档、Root Motion、独立导出骨架、显式 FBX Profile、MoCap 来源映射与 Body 采样烘焙。
- 脊柱变段数替换：四、六、八段之间的 FK/IK 姿态和动画迁移；自生成单／双 Skin、面部目标、原生动画附件、显式 DG 节点及嵌套角色命名空间场景经过接管验证。替换计划可设网格和身体误差上限；失败回滚，成功后可单次 Undo/Redo。
- Maya 角色工作台已有后台控制层与无窗口 Qt 排版验证。

## 验证

- 392 项纯 Python 回归测试。
- Maya 2024 `mayapy` 后台使用自行生成的骨架、网格和动画验证构建、写键、场景读回、撤销／重做、保存重开与独立进程输出。具体脚本和适用范围见 [`validation/README.md`](../validation/README.md) 与 [`剩余开发清单.md`](剩余开发清单.md)。
- 这些场景只证明列出的输入和离散采样时刻。帧间误差、任意拓扑、复杂插件依赖和真实生产资产仍需单独验收。

## 尚未完成

可见 Maya 会话的交互操作、完整原工具行为清单、外部生产角色与动画、更多 Face/变形依赖组合、自动 MoCap 映射及外部 FBX 导入尚未完成全量验收。Blender 保留早期可行性代码，正式第二阶段尚未开始。当前实现适合继续集成和验证，不应作为无条件的原工具替代品。
