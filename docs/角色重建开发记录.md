# 角色重建开发记录

状态：保留数据快照、替换 Rig 暂存构建、原曲线 / 蒙皮 / 独立附件接线交接已实现。旧 Rig 的所有权审计、清理与原位命名替换尚未实现；当前流程保留旧 Rig，不执行最终删除。

## 保留数据

`CaptureBodyCharacterPreservation(host).execute(extensions=())` 只读采集指定角色。`CharacterPreservation` 包含角色登记、当前姿态、时间、帧率、命名空间、原生曲线、关联蒙皮及显式声明的用户扩展。

动画记录原生节点 UUID、输入输出、关键帧时间和值、入出切线类型和角度、切线权重、锁定状态、breakdown 标记以及首尾循环方式。接线交接保留这些原节点及数据，只迁移命名空间和对应控制目标。

蒙皮记录原节点 UUID、关联 mesh 身份及顶点数、蒙皮设置、影响矩阵的逻辑索引、绑定前矩阵及其输入、稀疏权重存储、双四元数混合权重和节点连接。稀疏存储中的零权重条目保留，不使用既有权重文档的零值过滤规则。

用户扩展通过明确的根节点传入，并包含其 DAG 后代。记录父级、局部矩阵、UUID、节点类型、自定义属性和连接。支持标量、字符串、枚举、矩阵、消息属性，记录上下限、软限制、默认值、枚举定义、父属性及显示状态；数组和其他未支持的数据类型明确拒绝，不能静默跳过。扩展节点上的原生时间动画也纳入曲线快照。

Maya 原生写键可能为命名空间内的附件创建根命名空间曲线。仅当该曲线为非引用、未锁定的原生时间曲线，且全部输出属于显式声明的附件时，允许作为保留对象迁移。另一角色命名空间中的曲线仍拒绝接管。自定义属性按明确的当前时间上下文读取，避免跨帧检查后读到上一帧缓存。

```python
from adv_py.adapters import MayaBodyBuildHost
from adv_py.application import CaptureBodyCharacterPreservation

host = MayaBodyBuildHost(namespace="hero")
# 路径采用本角色内部地址，由实际附件父级决定。
snapshot = CaptureBodyCharacterPreservation(host).execute(
    extensions=("|UserAttachment",),
)
print(snapshot.content_digest)
```

快照为不可变数据对象，摘要覆盖曲线切线、蒙皮矩阵和扩展属性。采集结束复查角色登记与键值结构，不改变当前时间、选择或文件修改状态。

## 替换 Rig 暂存

`StageBodyCharacterRebuild(host).apply(namespace, extensions=())` 先取得保留快照，再从原角色 Fit 数据构建新的 Body、控制 Rig、登记和相同动画扩展。Fit 文档通过临时文件传递，流程结束删除临时文件。

```python
from adv_py.adapters import MayaBodyBuildHost
from adv_py.application import StageBodyCharacterRebuild

host = MayaBodyBuildHost(namespace="hero")
staged = StageBodyCharacterRebuild(host).apply("hero_rebuild")
print(staged.namespace, len(staged.registration.channels))
```

源角色必须显式选择命名空间；根角色使用 `namespace=""`。暂存目标必须为非根、无节点和子命名空间的名称。暂存结束，源角色仍承担原动画和变形，新 Rig 保持中性状态；两者共存，尚未发生数据交接。

当前暂存合同要求 Body 路径、父级和控制语义一致，绑定矩阵分量误差不超过 `1e-6`。不同拓扑、增减关节或改变绑定布局需要明确迁移规则，目前拒绝作为同布局替换处理。暂存前后比较完整保留快照，发现原角色改动即回滚。

源角色事务拥有唯一 Maya Undo 块。暂存适配器的应用操作加入该事务，不在内部异常时提前执行 Undo。撤销移除暂存 Rig，重做恢复登记和节点。Maya 可能保留空命名空间，该空身份允许再次使用。首次 IK 系统查询在根命名空间初始化默认求解器，避免不参与 Undo 的系统节点残留在暂存空间。

## 已有运行证据与下一步

### 原生数据交接

```python
from adv_py.application import TransferStagedBodyCharacterData

# staged 为同一次 StageBodyCharacterRebuild 返回的对象。
TransferStagedBodyCharacterData(host).apply(staged)
```

提交前核对源角色完整快照和暂存登记，拒绝被编辑过的源数据或已经接入动画的暂存控制器。交接包括：

- 把原曲线输出改接到同语义的新控制器，保留曲线 UUID、原键、切线、循环方式和时间输入。
- 把现有 skinCluster 的影响矩阵与锁定权重连接改接到新关节，同时迁移绑定姿态节点对关节的引用；保留 mesh、skinCluster、影响逻辑索引、全部权重和绑定前矩阵。
- 把独立用户附件及其后代保留在原节点上，迁移父级和相关 Rig 输入，保留局部变换、自定义属性及附件动画。
- 按原角色策略为新脊柱配置独立精确求解器，复制未动画化的控制值和空间偏移。

复检覆盖原关键帧、相邻关键帧中点及当前帧，最多 2000 个采样；同时比较身体和空间矩阵、实际蒙皮顶点、附件世界矩阵及数值属性。原生曲线和蒙皮存储另做完整结构比较，不能只靠有限采样证明数据完整。任一比较失败，整笔交接回滚。Undo 恢复原角色驱动关系，Redo 恢复交接。

交接完成后，原曲线驱动暂存命名空间中的 Rig，原 mesh / skinCluster 仍保留原名称，附件保留原节点名称并挂到新父级。旧 Rig 和两个登记暂时共存。这个中间状态支持保存重开，尚未完成原位替换。

### 控制器附加属性

保留快照自动采集登记节点上的用户属性。暂存时比较新旧节点，识别新 Rig 中缺少的附加属性；交接时先创建定义，再迁移原生动画与附件连接，最后恢复锁定状态。保留类型、默认值、数值上下限、软限制、枚举显式编号、显示名称、通道框状态和当前值。字符串未赋值与空字符串保持区别。当前接受标量数值、枚举、字符串、矩阵和消息属性；数组与需要新建的复合属性拒绝迁移。

例如 `userGain` 为默认值 `0.5`、范围 `0..2`、软限制 `0.1..1.5` 的浮点属性，在第 `1 / 11 / 21` 帧取值 `0.3 / 1.2 / 0.8`，并驱动附件的 `drivenGain`。交接保留原曲线 UUID，将其输出和附件输入连接到新控制器。源动画属性或附件输入被锁定时，仅在改接期间解除目标插头锁定，结束后恢复。`Manual=0:Auto=7:Done=9` 枚举保留非连续编号，不能按显示顺序重新编号。
